# 戦国期（1550〜1570年代）の武芸流派・伝書・兵法書 時代考証資料

- **作成**: Claude Code（2026-11-07）
- **きっかけ**: プロジェクトオーナーからの質問です。「武芸や武術が書かれた書物や口伝は、戦国期にどの程度あったのか。盛んになるのは江戸に入ってからか」。
- **照合したデータ**: `data/master_npcs_and_trials.json`（師匠NPCの段階別上限 70→85→100）、`data/skills_16_lines.json`、`07_sengoku_arms_and_tools.md`
- **証拠区分**: `[A]` 一次史料・確立した通説／`[B]` 軍記・後世の覚書・流派の記録／`[C]` 流派の伝承・後世の口伝／`[D]` ゲーム向けの翻案
- **確認の度合い**: **【Web確認】**＝調査時にWeb上の辞典・自治体・研究資料で記述を確かめたもの／**※要原典照合**＝専門書や流派の伝書そのもので確かめるまで断定しないもの

> **注意**: 流派の創始年の多くは、流派自身の伝承に基づいています。辞典どうしでも年代がずれることが多いので、この資料ではずれている場合は両方の説を載せています。

---

## 0. 結論

1. **流派と伝書は、戦国期にすでにあった。** 剣術・槍術・弓術・砲術・組討（柔術）のそれぞれに、16世紀に開かれたとされる流派がある。1563年には、上泉信綱が柳生宗厳に印可と絵目録を与えている `[A/B]`。
2. **ただし、技の中身はほとんど口伝だった。** 戦国期の伝書は、技の名前を並べた目録・奥義を伝えた証明である印可状・入門のときの誓約書である起請文が中心だった。技の具体的なやり方は紙に書かず、口で伝えた `[A]`。
3. **武術の書物が増え、流派が一気に増えるのは江戸時代から。** 今「戦国の兵法」として知られている書物の多くは、江戸時代に書かれている（§3）。
4. **戦国期に「兵法」と言えば剣術のこと。** 剣術家は「兵法者」と呼ばれた。軍学の意味の「兵法」が広まるのは、江戸時代の軍学からである `[A]`。

## 1. 戦国期にあったとされる主な流派

### 1-1. 剣術（当時の呼び方は「兵法」）

| 流派 | 開いた人・時期 | 要点 | 区分 |
| :--- | :--- | :--- | :--- |
| **天真正伝香取神道流** | 飯篠長威斎家直。室町中期。 | 門下から上泉信綱・塚原卜伝・松本備前守・諸岡一羽などが出て、それぞれ流派を開いたとされる。【Web確認：千葉県・千葉市の文化財解説】 | `[B/C]` |
| **鹿島新當流** | 塚原卜伝（1571年没）。 | 卜伝は香取神道流を学び、家に伝わる剣術を一つの流派にまとめたとされる。諸国を巡って教えた兵法者の代表格。 | `[B/C]` |
| **陰流（愛洲陰流）** | 愛洲移香斎。15世紀末。 | 新陰流のもとになった流派。【Web確認：コトバンク】 | `[B/C]` |
| **新陰流** | 上泉伊勢守秀綱（のち信綱）。永禄年間（1558〜70）。 | 1563年（永禄6年）の秋に奈良で柳生宗厳と出会い、2年後に「一国一人の印可」と「新陰流絵目録」4巻を与えたとされる（日本大百科全書）。前橋市の資料には、印可状の文言の一部が載っている。【Web確認】 | `[A/B]` |
| **立身流** | 立身三京。永正年間（1504〜21）。 | 伊予で開かれたと伝わる。【Web確認：千葉市】 | `[C]` |

- **出雲編との接点**: 1563年は、白鹿城の戦いと同じ年です。出雲で毛利と尼子が戦っていたちょうどその頃、奈良では剣術の印可がやり取りされていました。
- **ゲームへの示唆** `[D]`: 諸国を巡って教える兵法者は、旅の途中で出会う師匠NPCとして自然に登場させられます。

### 1-2. 槍術

- **宝蔵院流**: 奈良・興福寺の宝蔵院の僧、覚禅房胤栄（1521〜1607）が開いた。十文字の鎌槍で知られる。【Web確認：コトバンク】
  - **開いた時期は資料によって違う**。1560年代とする資料と、日本国語大辞典のように江戸初期とするものがある。
  - 胤栄は1563年に上泉信綱から新陰流を学び、それを槍術に取り入れたとされる `[B]`。
  - 猿沢池に映った三日月を見て十文字槍を考えついた、という話は伝承 `[C]`。
- **ゲームへの示唆** `[D]`: 僧が槍術の流派を開いたという事実は、系統8「仏門法術・僧兵」と系統2「長柄」を掛け合わせた二つ名の根拠になります。

### 1-3. 組討・柔術

- **竹内流**: 竹内中務大夫久盛が開いた。初めは「竹内流腰之廻」と名乗り、捕縛術・組討・小刀の技を含んでいた。【Web確認：コトバンク】
  - **開いた時期**: 「天文元年（1532）6月」とする辞典と、「天文年間（1532〜55）頃」とする辞典がある。
  - **場所**: 美作の出身。美作の一ノ瀬城と関係があるとする解説もある。
  - **「日本最古の柔術」という位置づけについて**: こう説明されるようになった経緯そのものが、最近の研究（スポーツ人類学研究、2020年）で見直されている `[C]` ※要原典照合。
- **出雲編との接点**: 美作は出雲の隣の国で、当時の尼子氏の勢力が及んでいた地域です。系統3「組討・体術」の師匠を山陰・山陽から出す根拠になります `[D]`。

### 1-4. 砲術

- **津田流**: 津田監物算長が開いた。種子島で砲術を学び、根来寺の門前町の鍛冶に鉄砲の作り方を教えたと伝わる。【Web確認：コトバンク・国土交通省】
  - 没年は、1567年とする辞典と1568年とする資料がある。
  - 1560年代には、すでに砲術の流派があったことになる `[B]`。
- **稲富流**: 稲富一夢（祐直、1552〜1611）が開いた。【Web確認：コトバンク】
  - 秘伝書には、鉄砲の起源・撃つときの心得・火薬の調合・照準の道具などが書かれている。
  - 福岡藩の黒田家、米沢藩の上杉家、彦根藩の井伊家など、多くの大名家に採用された。
  - 一夢の活躍は天正年間以降なので、**出雲編（1562〜66）の時点では、まだ若い**。
- **ゲームへの示唆** `[D]`: 系統5「銃砲・火器」の師匠は、根来や紀伊の鉄砲衆（津田流）の系統とすると、時代に合います。

### 1-5. 弓術・馬術（※今回はWebで確認できなかった）

- **弓術**: 日置流（日置弾正正次、15世紀後半）、そこから分かれた吉田流（吉田重賢、16世紀前半）。弓と馬の作法や礼法を伝える小笠原流もある。いずれも ※要原典照合。
- **馬術**: 大坪流など ※要原典照合。
- 弓は、戦国期を通じて負傷原因の首位だった武器（`07_sengoku_arms_and_tools.md` §1-0）なので、流派の層は厚かったと考えられます。

## 2. 戦国期の伝書の形と、口伝の役割

| 伝書の種類 | 中身 | ゲームでの使い方の案 `[D]` |
| :--- | :--- | :--- |
| **目録** | 流派の技の名前を並べた巻物。技の中身はほとんど書かれず、「口伝」とだけ記されることが多い。 | 手に入れると、技の名前と存在がわかる（技の一覧に名前だけ載る）。 |
| **絵目録** | 技の構えなどを絵で示した目録。上泉信綱が柳生に与えた「新陰流絵目録」が例。 | 構えの絵から、技の型だけを先に覚えられる。 |
| **印可状** | 奥義まで伝えたことを証明する書状。「一国一人」のように、印可を与える人数を限ることもあった。 | 師匠の段階上限（70→85→100）を解放する。一国一人＝その国でただ一人だけが持てる称号にする。 |
| **起請文** | 入門するときに、教えを他にもらさない、師にそむかないと神仏に誓う誓約書。 | 入門の儀式にする。ほかの流派へ移ると誓いを破ったことになり、評判が下がるなどの制約がかかる。 |

- **口伝が中心だった理由**（一般的な理解として）`[A/B]`
  - 技は、体で覚えるもので、言葉や絵だけでは伝わらない。
  - 流派の秘密を守るため、肝心な部分は紙に残さなかった。
  - 印可や目録を与えることそのものが、師匠の権威や収入の源になっていた。
- **この作品との相性**: 「伝書には名前しか書いていない。中身は師匠から口伝で受け取るしかない」という当時の仕組みは、`master_npcs_and_trials.json` の師匠NPCの段階別上限と、そのまま重なります。
  - **目録を手に入れる → 口伝を受ける → 印可を受けて上限が解放される**、という三段階にすると、史実をそのまま仕組みにできます `[D]`。

## 3. 兵法書（軍学）と、江戸時代にできた書物

### 3-1. 戦国期に読まれていたもの

- **中国の兵書**: 『孫子』などの武経七書（中国で11世紀に定められた七つの兵書）`[A]`。
- **足利学校**（下野）: 全国から学徒が集まり、儒学・易学・医学・兵学などを学んだとされる。ザビエルは「日本で最大にして最も有名な大学」と書いた `[A]`。【Web確認】
  - ただし、足利学校が軍配者を育てる場所だったかどうかは、研究者の間で意見が分かれている。儒学の学校で、兵学はおまけのようなものだったという見方もある `[B]`。
- **軍配者（軍師）の実像**: 易や占いで、戦の日取り・方角・吉凶を決める役目が中心だった。陰陽師・修験者・僧を迎えた大名も多かった `[A/B]`。【Web確認：小和田哲男の談話】
  - 「軍略を練る天才軍師」というイメージは、後世の軍記や江戸時代の軍学によるところが大きい。
  - **ゲームへの示唆** `[D]`: 系統9「陰陽道・天文」は、戦国期の軍配者の実像にそのまま当てはまります（式盤・暦算・五色護符）。

### 3-2. 江戸時代にできた書物（「戦国の兵法」として知られるもの）

| 書物 | 成立 | 注意 |
| :--- | :--- | :--- |
| 『甲陽軍鑑』 | 江戸初期にまとめられた | 武田家の軍学書。戦国期の当事者の記録ではない `[B]`。 |
| 『雑兵物語』 | 江戸初期 | 足軽の戦い方を語る兵法書（`07` §1-2 で槍を「叩く」用法の典拠にしたもの）`[B]`。 |
| 『兵法家伝書』 | 1632年（柳生宗矩） | 新陰流の理論書 `[A]`。 |
| 『五輪書』 | 1645年（宮本武蔵） | `[A]` |
| 『万川集海』 | 1676年 | 忍術書（`07` §4-3）`[A]`。 |
| 『本朝武芸小伝』 | 1716年（日夏繁高） | 武芸の流派の系譜をまとめた書物 `[B]`。 |
| 「武芸十八般」 | 江戸時代 | もとは中国の概念。日本の武芸の一覧として使われるようになったのは江戸時代 `[A]`。 |

- **小説・台詞での注意**: 1560年代の人物に『五輪書』や『甲陽軍鑑』を引用させたり、「武芸十八般」と言わせたりすると、時代に合わなくなります。

## 4. スキル設計への提案まとめ `[D]`

1. **伝書は三段階にする**
   - 目録：技の名前がわかる
   - 口伝：師匠から教わり、技が使えるようになる
   - 印可：上限が解放される
   - 師匠NPCの 70→85→100 の上限と対応させる。
2. **起請文で入門する**: 流派ごとに誓約を交わす。ほかの流派も学ぶ場合は、誓いとのかね合いでペナルティか特別な試練がある。複数の流派を極めた者は、隠し職の条件にする。
3. **諸国を巡る兵法者を師匠にする**: 塚原卜伝や上泉信綱のような諸国を巡る兵法者を手本にして、旅の途中で師匠と出会えるようにする。オープンワールドを漂泊するという作品の方針と合う。
4. **流派の系統と土地を結びつける**
   - 剣術：鹿島・香取（東国）から、上泉・柳生（上野・大和）
   - 槍術：宝蔵院（奈良の寺院）
   - 組討：竹内流（美作。出雲の隣の国）
   - 砲術：津田流（紀伊・根来）
   - 武芸を学ぶことが、ほかの国へ旅する動機になる。
5. **軍配者を系統9にする**: 戦国期の軍師は、占いと暦を扱う者だった。系統9「陰陽道・天文」を戦場で使うと、陣の吉凶や天候を読む力になる。

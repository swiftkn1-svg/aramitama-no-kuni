# 補遺10：戦国期の忍び（透破・乱波・草・かまり）と忍具の時代考証

> **目的**: 忍び（系統6）の手と忍具の種類分けを決めるために、戦国期（1540〜1580年）の忍びの実際の姿を史料で確かめます。あわせて、江戸期の忍術書から来たもの、近代のイメージから来たものを切り分けます。
> **証拠区分**: `[A]` 一次史料・同時代記録（書状・掟書・日記） / `[B]` 軍記・江戸期の忍術書（『万川集海』『正忍記』など） / `[C]` 口伝・俗説・近現代のイメージ / `[D]` ゲーム的な提案
> **表記**: 【Web確認】＝今回Web上の資料で確かめた項目。「※要原典照合」＝まだ原典で確かめていない項目。
> **関連資料**: 05（傀儡子・座頭・高野聖などの五職能）、09（摩利支天・不定時法）、10（足軽の実態・§6 戦闘設計・崩しゲージ）。

---

## §0 結論（先に要点）

1. **戦国の忍びは「夜の戦の専門家」として雇われた者たちでした。**
   - 仕事の中心は、夜討ち・城への忍び込み・放火・城の乗っ取り・待ち伏せ・敵情の探りです `[A]`【Web確認】。
   - 平山優は、戦国の戦いは夜も休みなく続き、夜の戦場の主役は忍びだったと述べています（カドブンのインタビュー）。
   - 出自は、伊賀・甲賀のような土豪もいましたが、多くは「悪党」（盗賊などで暮らしていた者）だったとされます。大名の軍では足軽として編成されました `[A]`（平山2020の解釈）。
2. **呼び名は地域で違いました。「忍者」は昭和30年代の言葉です。**
   - 史料上の呼び名は「忍び」です。ほかに透破（すっぱ）・乱波（らっぱ）・草・かまり・伏などがあります。
   - 平山によれば、「草」は東北・東日本だけで、西日本には例がありません。「かまり」は関東・甲信・東海に限られます。「伏」は全国で見られます【Web確認】。
3. **忍具と忍術は、ほとんどが江戸期の忍術書から来ています。**
   - 忍具の体系は『万川集海』（1676年）、「忍び六具」や「七方出」は『正忍記』（1681年）が出どころです `[B]`。
   - 戦国期の文書で、道具の名前まで確かめられたものは、今回は見つかりませんでした。
   - 手裏剣は、見つかっている忍術書に記述がありません。黒装束は、歌舞伎や浄瑠璃など演劇から広まったと考えられています `[C]`【Web確認】。
4. **ゲームでは「夜・下準備・人に紛れる」の三つを、忍びの軸にするのがよいと考えます。** 道具は、江戸期の分類（登器・水器・開器・火器）を土台にしつつ、戦国らしさを損なうもの（手裏剣・黒装束）は扱いを絞ります（§6）。

| 呼び名 | 意味・使われ方 | 地域・史料 | 区分 |
| :--- | :--- | :--- | :--- |

| **野臥（のぶせり）** | 史料上は「足軽」と書かれた他国の忍びの一種 | 平山2020（意味の詳細は※要原典照合） | `[A]` |
| **忍者** | 近代の呼び名 | 昭和30年代に広まる | `[C]`【Web確認】 |

  - 風魔については、『北条五代記』は創作性が強い一方で、ほかの史料による裏付けもあるとされます `[B]`。
  - それ以外の三つは、戦国期の文書での確認は今回できませんでした（※要原典照合）。

## §3 忍びの身分と雇われ方

| 項目 | 内容 | 区分 |
| :--- | :--- | :--- |
| **出自** | 伊賀・甲賀の土豪（武士身分）もいたが、ほとんどは悪党出身（盗賊などで暮らし、夜の活動が得意だった者）だった、と平山は述べる | `[A]`（平山の解釈） |
| **軍の中での扱い** | 透破や野臥は、史料上「足軽」と書かれる。忍びは足軽として編成されていたと考えられる | `[A]`（平山2020） |
| **雇い賃** | 浅井長政は20貫文で伊賀衆を雇った（1561年） | `[A]` |
| **伊賀の自衛** | 惣国一揆掟書で、17〜50歳の男が陣に出ることを定めた。百姓でも城攻めで手柄を立てれば侍に取り立てる、という趣旨の条文があるとする解説もある（※要原典照合） | `[A]` |
| **悪党とのつながり** | 鎌倉末〜南北朝の黒田荘の悪党は、道の封鎖・城づくり・放火・夜討ち・山賊・強盗をしていた。平山は、これを戦国の忍びと同じ行動とみる | `[A]`（平山の解釈） |

### 5-4 印と呪符 `[B]`【Web確認】

- 忍術書に印の結び方はほとんど出てきません。『万川集海』に一か所だけ、身を隠すときに印を結んで「オンアニチマリシエイソワカ」と唱えよ、とあります。
- これは摩利支天の真言です。摩利支天は、姿を隠して身を守る仏として武士に信仰されました（09 §3）。
- 『正忍記』には、人間関係を良くしたり悪くしたりする呪符を含む「五種の呪符」があります。
- 「くノ一」は、『万川集海』では「女」の字を三つの字に分けた言葉で、女性を潜入させる術のことです。女性の忍者がいた記録は見つかっていません `[B/C]`【Web確認】。

## §6 ゲーム化の提案 `[D]`

### 6-1 忍び（系統6）の軸：夜・下準備・人に紛れる

- **夜**
  - 忍びの手は、夜にいちばん強くなるようにします。
  - 本作では、影が長いほど瘴気の潮位が上がります（企画書第10章）。夜は忍びが働ける時間ですが、瘴気がいちばん濃い時間でもあります。この危うさがそのまま忍びらしさになります。
  - 時刻は不定時法（09 §5）で数えます。
- **下準備**
  - 忍具は「使い捨て」で、「戦う前に仕込むと強い」性格にします（10 §6 の合意どおり）。
  - 正面からの昼の戦いには弱くします。忍び自身が「なるべく戦わない」者だった、という解説にも合います。
- **人に紛れる**
  - 七方出を「変装」の仕組みにします。姿によって、通れる関所・入れる場所・聞ける噂が変わります。
  - 05 の五職能（傀儡子・座頭・高野聖など）や、02 の座・行商とつながります。

### 6-2 忍具の種類分け

| 分類 | 道具の例 | ゲームでの役目 | 使い捨てか | 作る系統 | 区分 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **登器** | 鉤縄・苦無 | 高い所へ登る。巨体の荒魂に取り付く（10 §6 の「取り付き」） | 回収できる | 細工・紡織（12）、採掘・鍛冶（10） | `[B]`＋`[D]` |
| **水器** | 水蜘蛛（湿地用の浮き具） | 泥田・湿地を渡る。水上を歩くことはできない | 回収できる | 伐採・木工（11） | `[B]`＋`[D]` |
| **開器** | 錐・鋸などの道具（具体名は※要原典照合） | 戸・錠・結界の綻びを開ける。探索 | 損耗する | 採掘・鍛冶（10） | `[B]`＋`[D]` |
| **火器** | 火矢・狼煙・付竹（火種入れ） | 放火・合図・明かり。泥鎧を乾かす／燃やす | 使い捨て | 採取・本草（13）、銃砲（5） | `[B]`＋`[D]` |
| **罠具**（ゲーム独自） | 張り縄・撒菱・竹槍の落とし穴 | 通り道に仕込んで足止め・転倒（崩しゲージを削る） | 使い捨て | 細工・紡織（12）、伐採・木工（11） | `[D]` |
| **撹乱具**（ゲーム独自） | 目潰し（灰など）・鳴り物 | 狙いを外させる・注意をそらす | 使い捨て | 採取・本草（13） | `[D]` |

- 目潰しの中身に唐辛子を使うかどうかは、唐辛子が日本に入った時期が戦国期のどこか（16世紀半ばか末か）で説が分かれるため、※要原典照合とします。灰や砂なら問題ありません。

### 6-3 扱いを絞るもの

| もの | 扱い | 理由 |
| :--- | :--- | :--- |
| **手裏剣** | 出すなら棒手裏剣だけにする。威力は低く、怯ませて逃げる道具にする | 忍術書に記述がない。手裏剣術は武士の武術 |
| **黒装束** | 使わない。茶・柿・紺の野良着や旅装にする | 演劇から広まったイメージ |
| **忍者という呼び名** | 作中では使わない。透破・乱波・草・かまり・忍び、と地域で呼び分ける | 昭和の言葉 |
| **くノ一** | 女性の忍者としては出さない。女性の登場人物が情報を集める役は、歩き巫女などの職能として描く | 史料上の意味が違う |
| **虚無僧** | 戦国期の場面では薦僧と呼ぶ | 宗派として組織されるのは江戸期 |

### 6-4 ほかの設計とのつながり

- **崩しゲージ**: 張り縄・撒菱・竹槍の落とし穴は、10 §6 で合意した崩しゲージに従います。転倒のたびに次が効きにくくなるので、罠を重ねてハメ続けることはできません。
- **雇われの忍び**: 伊賀衆を20貫文で雇うなど、NPC の傭兵として雇える仕組みにできます（浅井長政書状 `[A]`）。
- **霊威なし**: 忍びは戦闘系なので、霊威を持ちません（10 §6-1）。摩利支天の隠形の印を使うには、仏門法術（系統8）との組み合わせが要ります。たとえば、隠し秘伝職「摩利支天の隠れ身」のような形です。
- **地域の呼び名**: 出雲編（西日本）では「草」は使わず、「忍び」「乱波」などを使います（平山：西日本に「草」の例なし）。

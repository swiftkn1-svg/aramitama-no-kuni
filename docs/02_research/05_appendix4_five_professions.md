# 『荒魂の國』補遺4 五職能と五儀礼の追加調査

- **対象**: 1540～1580年を中心に／2026年10月25日
- **Google Docs 原典（非公開）**: 荒魂の國｜補遺4 五職能と五儀礼の追加調査

## 1. 五職能（地域別の職制・道具・伝書）
- **① 傀儡子（くぐつし）**: 摂津西宮の散所と百太夫神社（えびすかき：[西宮神社公式](https://nishinomiya-ebisu.com/guide/hyakutayuu/)）、および淡路人形座の『道薫坊伝記』・1570年宮中奉納伝承（[淡路人形座公式](https://awajiningyoza.com/history/)）。ゲーム内では木工×細工×音曲の隠し複合職『傀儡師』として統合。
- **② 座頭（ざとう）**: 京都の当道（久我家本所・1534年座中天文事件：[山川日本史小辞典](https://www.historist.jp/word_j_to/entry/035711/)）および1563年成立『玉塵抄』巻27「ここらに座頭の検校が琵琶をけっこうして」の同時代用例（[コトバンク：座頭](https://kotobank.jp/word/%E5%BA%A7%E9%A0%AD-68495)）。
- **③ 馬借（ばしゃく）**: 越前の河野・今泉両浦と山内の馬借集団、および天文21年（1552）7月の「里買塩」運搬差止め訴訟（『福井県史』資料編6「西野次郎兵衛家文書」43号：[福井県史年表](https://www.library-archives.pref.fukui.lg.jp/fukui/07/nenpyo/rekishi/chrn23.html)）。
- **④ 高野聖（こうやひじり）**: 唱道・勧進・納骨の担い手（[浄土宗大辞典](https://jodoshuzensho.jp/daijiten/index.php/%E9%AB%98%E9%87%8E%E8%81%96)）。『洛中洛外図屏風（歴博甲本）』右隻第6扇に描かれた独特の「黒い笈」を背負う二人連れ（[国立歴史民俗博物館](https://www.rekihaku.ac.jp/education_research/gallery/webgallery/rakutyuu/theme/work25.html)）。ゲーム内では「仏門×商い」の正規複合職として統合。
- **⑤ 鷹匠（たかじょう）**: 信濃の諏訪・大宮流と禰津一族。『鷹書』の天文15年（1546）写本・弘治3年（1557）写本候補（[国書データベース](https://kokusho.nijl.ac.jp/biblio/100116682)）および天正12年（1584）奥書『鷹書才覚巻抄出』翻刻に見える「ゆかけ・鞭・犬飼の杖」と鷹を仏とみなす不浄回避（[二本松泰子論文PDF](https://www.ritsumei.ac.jp/acd/cg/lt/rb/622/622PDF/nihonma.pdf)）。

## 2. 五儀礼（宗派・流派・年代別の根拠）
- **① 引導（いんどう）**: 葬儀において導師が新亡に法語を与え行くべき世界を教示する作法（下炬＝松明投下とは本来別：[浄土宗大辞典](https://jodoshuzensho.jp/daijiten/index.php/%E5%BC%95%E5%B0%8E)）。曹洞宗・永光寺の戦国末〜寛永期「切紙・門書」における没後作僧儀式。
- **② 施餓鬼（せがき）**: 『幻住庵清規』附録『開甘露門』の三部構成（施食法要・受戒儀式・回向：[妙心寺研究紀要PDF](https://www.myoshinji.or.jp/educate/bulletin/pdf/kiyou-vol.04/comitee%20for%20zen%20buddhism%20studies;the%20origin%20of%20kai-gan-lu-men,which%20used%20in%20japanese%20zen%20sect.pdf)）と、普集餓鬼陀羅尼・開地獄咽喉陀羅尼・変食陀羅尼・五如来宝号の流れ（[浄土宗大辞典](https://jodoshuzensho.jp/daijiten/index.php/%E6%96%BD%E9%A4%93%E9%AC%BC%E4%BC%9A)）。
- **③ 神社祭祀（中臣祓と諏訪再興）**: 吉田兼倶流の中臣祓（13段構成：[國學院大學展示](https://www2.kokugakuin.ac.jp/kaihatsu/oharai/theme_b.html)）と、永禄8年（1565）11月の武田信玄による諏訪社祭祀再興下知状（[長野県立歴史館](https://shinshu-dcommons.pref.nagano.lg.jp/museum_history/03OD0624100900)）。
- **④ 不動護摩（ふどうごま）**: 醍醐寺伝来・興然撰『不動護摩次第』（護摩壇上の法具配置図付き：[奈良国立博物館](https://www.narahaku.go.jp/collection/1131-0.html)）。
- **⑤ 六字河臨法（呪詛返し・調伏息災）**: 文応元年（1260）後嵯峨上皇の平癒修法を記録した『六字河臨法記』（二艘の船に板を渡した船上道場・七瀬の祓：[奈良国立博物館](https://www.narahaku.go.jp/collection/1432-0.html)）および円鏡と六呪詛神を描く『六字経曼荼羅図』（[京都国立博物館](https://knmdb.kyohaku.go.jp/21872.html)）。

# 戦国期（1550〜1570年代）の武器・武具・職能道具 時代考証資料

- **作成**: Claude Code（2026-11-07）
- **依頼元**: アルテ（スキル16系統と装備・小道具の仕様を詰めるための考証調査）
- **照合したデータ**: `data/skills_16_lines.json`、`docs/01_spec/MASTER_VISION_v2.2.md`、小説の第四幕・第五幕
- **証拠区分**:
  - `[A]` 一次史料・出土遺物・確立した通説
  - `[B]` 軍記・当時の記録・後世の覚書
  - `[C]` 民俗・後世の口伝
  - `[D]` ゲーム向けに翻案できる余地
- **確認の度合い**:
  - **【Web確認】** 調査時にWeb上の辞書・博物館・公的資料・研究報告で記述を確かめたもの
  - **※要原典照合** 専門書や史料で確かめるまで断定しないもの

> **調査の限界**: 今回はWeb上の資料だけで調べています。武器ごとの防御力や威力を数値で示した史料はないため、ゲームの数値はすべて `[D]` として設計してください。
>
> 戦国期の武器考証には、軍記物、江戸時代の兵法書（『雑兵物語』など）、時代劇やゲームによって後から作られたイメージが多く混ざっています。この資料では、そうしたイメージと当時の実態を分けることを優先しました。

## 1. 近接兵器の実態と使い方

### 1-0. 前提：戦場で何によって傷を負ったか 【Web確認】
鈴木眞哉が軍忠状などに記された負傷の原因を集計しています（『刀と首取り』『「戦闘報告書」が語る日本中世の戦場』）`[A: 一次史料の集計]`。

| 負傷の原因 | 戦国期全体 | 戦国後期 |
| :--- | :--- | :--- |
| 矢疵 | 約38% | ― |
| 鉄砲疵 | 約24% | 約45%で首位 |
| 鑓疵（突疵） | 約20% | ― |
| 石疵（礫疵） | 約12% | ― |
| 刀疵 | 約4% | ― |

- **注意すべき偏り**
  - 集計できるのは生き残った者が自分で申告した傷だけで、死者の死因は含まれていない。
  - 記録は勝った側に偏っている。
  - 別の研究者が見直したところ、石疵の4分の1以上が天文21年（1552）7月23日の一つの戦いに集中していた。
- **ゲームへの示唆** `[D]`
  - 刀は「主力の武器」というより、「組み討ち・首取り・乱戦での最後の手段」にすると、史実の空気に近い。
  - 遠くから攻撃する手段（弓・鉄砲・石）が負傷原因の7割を超えていたことは、5属性の「貫通」「打撃」が射撃でも起きるという設計の裏づけになる。

### 1-1. 刀剣 【Web確認】
- **太刀と打刀の違い**
  - 太刀は刃を下に向け、紐で腰から吊るす（「佩く」）。
  - 打刀は刃を上に向け、帯に差す（「差す」）`[A]`。
- **打刀が主流になった時期**: 応仁の乱の後、室町時代後期から戦国期にかけて。足軽による徒歩の戦いが増えたことが背景にある `[A]`。
- **刃の長さの目安**（資料によって幅がある）`[A]`
  - 打刀：60cm（2尺）を超える
  - 脇差：30〜60cm
  - 短刀：30cm 前後以下
- **大小二本差し**: 打刀と脇差の2本を差す形が武士の決まった装いになったのは江戸時代 `[A]`。戦国期は、打刀に腰刀（短刀）を合わせる組み合わせも普通だった。
  - **ゲームへの示唆** `[D]`: 「大小」をそろえることを身分の印にするのは、時代として少し早い。
- **片手打ち**: 室町後期には、刃が短めで柄も短い打刀（いわゆる片手打ち）が多く作られたとされる ※要原典照合（今回のWeb調査では確かめられていない）。
- **鎧通し**: 刃の身が厚い短刀で、組み討ちのときに鎧の隙間を刺すためのもの `[A]` ※要原典照合（形と寸法）。系統3「組討・体術」の主な武器として妥当。

### 1-2. 槍 【Web確認・一部※要原典照合】
- **長さの規定**
  - 1572年の武田氏の軍役の史料に「長柄三間」「持鑓二間」という規定があるとされる。一間は約1.8mで、長柄が約5.4m、持鑓が約3.6m にあたる `[A]` ※要原典照合（Web上の二次的な紹介で確認しただけ）。
  - 足軽が持つ「長柄」と、武士が自分で持つ「持鑓」とは、長さで区別されていた。
- **「突く」と「叩く」**
  - 江戸初期の『雑兵物語』に、集団で戦うときは穂先をそろえ、拍子を合わせて上から叩けという足軽頭の言葉がある `[B: 江戸初期の兵法書]`。
  - 叩くか突くかの比率を数字で示した史料はない。
  - **ゲームへの示唆** `[D]`: 長柄の足軽は「叩く」（打撃・崩し）、持鑓の武士は「突く」（貫通）と、属性を分けると史実に近い。
- **穂先**: 素槍（まっすぐな穂）が基本で、穂が長いものを大身槍と呼ぶ `[A]`。具体的な寸法は ※要原典照合。

### 1-3. 打撃・破砕の武器
- **金砕棒**
  - 平安後期の記録に出てくるとされる。
  - 戦国期の合戦で使ったという確かな一次史料は、今回は見つからなかった。
  - 使い方を記した武術書も残っていない `[C/D]`。
- **鉞・鶴嘴**: まれに戦場で使われたとする研究者の指摘がある `[B]` ※要原典照合。
- **大槌**: 武器としての記録は確認できなかった。城門を壊したり杭を打ったりする工兵の道具として描くのが妥当 `[D]`。
- **推奨** `[D]`
  - 金砕棒は、荒魂退治のための特殊な武器（神事の打撃具）と位置づけ、人間同士の合戦の武器ではないと説明する。
  - 大槌は、系統11「伐採・木工」や系統10「採掘・鍛冶」の道具を戦闘にも使えるもの、とする。
  - 系統2の武器リストに残す場合は、`[D]` の印を付ける。
  - **追記**: 大槌については、§4-4 で「掛矢や工兵の道具が戦いに転じたもの」という位置づけを提案している。

## 2. 射撃・遠隔の武器と携行具

### 2-1. 和弓と矢
- **重籐弓**: 木と竹を貼り合わせた弓に籐を密に巻き、補強と装飾をかねたもの。格式の高い弓とされる `[A]` ※要原典照合（巻き方の種類による格の違い）。
- **塗弓**: 漆を塗って湿気を防いだ弓 `[A]`。
- **矢の種類** `[A]`
  - **尖り矢**: 戦闘で刺し通すための矢。
  - **雁股**: 先が二股に開いた鏃。狩りや、切り裂くための矢。
  - **鳴鏑（鏑矢）**: 合図や儀礼に使う。
- **破魔矢**: 正月の神事や縁起物で、民俗の領域のもの `[C]`。
- **ゲームへの示唆** `[D]`: 系統4の「大雁股矢」は切断属性、尖り矢は貫通属性、破魔矢と鳴鏑は霊威属性とすると、属性の割り当てに史実の根拠が持てる。
- **弓の役割**: 戦国期全体を通じて、負傷原因の首位は矢 `[A]`。鉄砲が広まった後も、弓は主力の武器として残った。

### 2-2. 火縄銃と付属品 【Web確認】
- **伝来と普及**
  - 天文12年（1543）頃に伝来 `[A]`。
  - 1563年の白鹿城攻めの時点で、すでに山陰の攻城戦の主力武器だった `[A]`。
- **弾の込め方**（銃口から込める方式）`[A]`
  1. 銃口から火薬を入れる。
  2. 弾を入れる。
  3. カルカ（込め矢）で突き固める。
  4. 火皿に口薬（点火用の細かい火薬）を盛り、火蓋を閉じる。
  5. 火縄を火挟み（蛇口）にはさむ。
  6. 火蓋を開けて撃つ。
- **早合**
  - 1回分の火薬と弾を、紙や竹の筒にまとめたもの。いまの薬莢のもとになった道具 `[A]`。
  - **いつ現れたかは確認できなかった** ※要原典照合。
  - 1560年代に出すなら、紙で包んだ1回分の火薬（紙包み）程度にとどめるのが安全 `[D]`。
- **口薬入れ**: 実物は名古屋城などに収蔵されているが、確認できたものの多くは江戸時代の作 `[A]`。
- **胴乱・火縄**: 当時どう携行したかの具体的な資料は、今回は見つからなかった ※要原典照合。
- **ゲームへの示唆** `[D]`: 上の6つの手順をそのまま「装填ミニゲーム」や装填の待ち時間にすると、手仕事の手触りというこの作品の方針に合う。雨で火縄が消える、火皿が湿るといった天候の影響もつけやすい。

### 2-3. 投げて当てる武器
- **印地（石打ち）**
  - 河原で二手に分かれて石を投げ合う遊び、またそれを得意とした集団を指す言葉 `[A]`。
  - 『平家物語』や『義経記』に、石合戦を得意とした軍勢として出てくる `[B]`。
  - 鎌倉時代に盛んで、死傷者が多く出て禁止されたこともあった `[A]`。
  - 投げ縄のような道具（いわゆる投石紐）で石を遠くへ飛ばす技も紹介されている `[B]` ※要原典照合。
  - 戦国期の負傷原因の約12%が石疵だったこと（§1-0）は、石が実際に戦場で使われていた裏づけになる `[A]`。
- **焙烙玉・焙烙火矢**
  - 火薬を詰めて投げ込む武器。防壁で囲まれた日本の軍船に対して、その隙間から投げ込むのが有効だったとされる `[B]`。
  - 毛利・村上水軍が木津川口の戦い（1576年）で使ったという話は広く語られているが、一次史料（『信長公記』など）の本文までは確かめられなかった ※要原典照合。
  - **1560年代の出雲編**で陸の戦いに使うのは `[D]`。使うなら、水軍や海辺の拠点（第二幕の神門水海など）に限るのが自然。

## 3. 防具・装束・足回り

### 3-1. 甲冑の移り変わり 【Web確認】
- **腹巻・胴丸**
  - 平安中・後期にはすでにあり、もとは徒歩の兵の鎧 `[A]`。
  - 応仁の乱の後、徒歩の集団戦が広がると、騎馬武者の大鎧に代わって主流になった `[A]`。
- **当世具足**
  - 鉄の板を使った胴に、籠手や脛当まで含めて全身を覆う一揃いの甲冑 `[A]`。
  - 辞典では「室町末期以降」とするものと「近世初頭の成立」とするものがあり、成立の時期ははっきりしない。
  - 室町末期までの札（小さな板）を綴った甲冑を「昔具足」、それ以後のものを「当世具足」と呼び分けた `[A]`。
- **桶側胴**: 鉄の板を横に並べて留めた胴で、当世具足のごく初期の形 `[A]`。
- **小説への示唆**
  - 第四幕の元春（1563年）の「黒糸威の当世具足」は、ぎりぎり許される範囲 `[D]`。
  - 「黒糸威の胴丸」とすれば確実に時代に合う。「桶側胴」とすれば新しいもの好きの猛将らしさも出せる。
- **防御力**
  - 切る・刺す・撃つそれぞれへの耐久度を数値にした史料はない。
  - **設計方針** `[D]`
    - 札を綴った鎧は、切られるのには強いが、刺されるのには弱い。
    - 鉄板の胴は刺突にも銃弾にもある程度耐える。ただし、近くからの銃撃は防げない。
    - 戦国後期には、試し撃ちをした跡（試し胴）がある胴も作られた ※要原典照合。
- **陣笠・御貸具足**（主君が足軽に貸し与える揃いの具足）: 今回は確かめられなかった ※要原典照合。

### 3-2. 足回り
- **草鞋**: 戦国期の旅や行軍の基本の履物 `[A]`。
- **足半（あしなか）**
  - かかとの部分がない短い草鞋で、ぬかるみや山道で滑りにくい `[A]`。
  - 武士や足軽が戦場で履いたと伝わる `[B/C]` ※要原典照合。
  - 系統3のパッシブ「泥中の体捌き」の装備品として使える `[D]`。
- **地下足袋**: **大正時代（20世紀）の発明なので、使えない**。今のところ、リポジトリの中で使われている箇所はない。
- **脛当・佩楯**: 甲冑の一部として、この時代にもある `[A]`。

## 4. 職人・曲者の実用道具

### 4-1. 番匠（大工）と石工 【Web確認】
- **墨壺・墨縄・曲尺**: 古代からある、線を引き寸法を測るための道具 `[A]`。
- **釿（ちょうな）・ヤリガンナ**: 古代からある、木の表面を削って整える道具 `[A]`。
- **大鋸（おが）**
  - 室町時代の初め（15世紀初頭）に中国の明から伝わった、二人で引く縦挽きの大きな鋸 `[A]`。
  - これで幅の広い薄い板を挽けるようになり、建築技術が大きく進んだ。
  - 一人で引く**前挽大鋸**も、15世紀には入っていたとする資料がある `[A]` ※要原典照合。
- **台鉋**: 室町後期に広まったとされる ※要原典照合（今回は確かめられなかった）。1560年代に出すなら、ヤリガンナと台鉋が混在している、という描き方が安全。
- **矢穴用の鉄矢・千切・鎹**
  - 矢穴の技術（`06_izumo_deep_dive.md` §5）は、鎌倉期に伝わったもの `[A]`。
  - 石材を大量に割るようになったのは慶長期から `[A]`。
  - 千切（木と木をつなぐ蝶形の栓）と鎹（コの字形の金具）は、木工・石工の継ぎ手として古くからある `[A]`。

### 4-2. 鍛冶と鉱夫
- **向こう鎚・金敷・鞴**: 鍛冶の基本の道具で、この時代にもある `[A]`。
  - 親方が小槌で打つ場所を示し、弟子が向こう鎚を振るう、という分担は描いてかまわない。
  - 鞴の時代考証は `06_izumo_deep_dive.md` §3 を参照。
- **鏨（たがね）・鎚**: 石見銀山の龍源寺間歩に、当時のノミの跡が残っている `[A]`。
  - ただし龍源寺間歩は1715年に開かれた坑道。
  - 戦国期の採掘については、1500年代後半から掘られた大久保間歩などを見るほうがよい。
- **坑内の灯り**
  - サザエの殻に油を入れた灯り（螺灯）については、今回は記述が見つからなかった ※要原典照合。
  - 松明や油を使った灯明皿は、どの時代にも当てはまる描写として使える `[D]`。
  - **カンテラは使えない**。オランダ語に由来する、江戸時代以降の道具。
- **練り香**: 第四幕で金掘り衆が使う秘伝の薫香は創作 `[D]`。坑内の悪い空気を払うための信仰の道具として描くなら、民俗的な説得力はある。

### 4-3. 忍び・曲者の道具
- **忍術書**
  - 『万川集海』は延宝4年（1676）の江戸時代の書物で、戦国期の実態をそのまま記録したものではない `[A]`。
  - それより古い可能性がある甲賀の『間林清陽』も、残っているのは1748年の写本 `[B]`。
- **鉤縄・水蜘蛛など**: 伊賀流忍者博物館などに実物がある `[A: 実物]`。ただし、作られた年代や戦国期に実際に使われたかははっきりしない `[C]`。
- **苦無・忍び刀（四角い鍔のまっすぐな刀）**
  - 今回の調査では、戦国期に実際に使われたという史料は見つからなかった。
  - 後世の創作や、江戸時代以降のイメージとみるのが妥当 `[C/D]`。
- **透破（すっぱ）・乱波（らっぱ）**: 軍記に出てくる、間諜や攪乱をする者の呼び名 `[B]`。系統6の名前として妥当。
- **推奨** `[D]`
  - 系統6の道具は、当時ふつうにあった道具を転用したものとして描く。たとえば縄、鉤、鎌、竹槍の罠、灰や唐辛子を使った目潰し。
  - 「忍具」として特別な形にした道具は、江戸時代の忍術書にしかない技（隠し技）として扱う。そうすると、史実と創作の境目をゲームの中で示せる。

### 4-4. 職人・百姓の道具を戦いに使った例（2026-11-07 追記）

プロジェクトオーナーから提案がありました。「職人や農民の道具を武器として使った記録はないか。斧や大槌は城攻めにも使われたはずで、戦闘スキルに昇華できるのではないか」というものです。これに答えるために追加で調べました。

**わかったこと**
道具そのものが武器として記録されている例は少ない一方で、**道具を使う人々が、その技術ごと戦いや城攻めに駆り出された記録**ははっきり残っています。

| 例 | 内容 | 区分 |
| :--- | :--- | :--- |
| **白鹿城攻めの銀掘り衆**（1563年） | 毛利軍が石見銀山の銀掘りを数百人呼び寄せ、坑道を掘って城の水脈を断たせた。城方も迎え撃つ坑道を掘り、地下で戦いになった。鉱夫の鶴嘴や鏨が、城を落とすための道具になった。詳しくは `06_izumo_deep_dive.md` §1-2。 | `[A/B]`（毛利家臣の覚書・軍記） |
| **黒鍬** | 戦国期から江戸期にかけて大名に仕え、陣地や橋を造ったり、戦死者を収容して葬ったりした土木作業の集団。今でいう工兵にあたる。名前の由来は、刃が厚く幅の広い、深く掘るための鍬とされる。 | `[A/B]` ※要原典照合（編制や道具の詳細） |
| **もぐら攻め** | 坑道を掘って城の中へ入ったり、井戸を壊したりする攻め方。武田信玄が得意としたと紹介されている。 | `[B]` ※要原典照合 |
| **百姓の武装と刀狩** | 豊臣秀吉の刀狩令（天正16年＝1588年）は、百姓が刀・槍・弓・鉄砲を持っていたことを前提にしている。条文も、武器を取り上げる理由に一揆を挙げている。前段階として、天正4年（1576）の柴田勝家の「刀さらへ」や、天正13年（1585）の紀伊での武具の没収がある。藤木久志は、刀狩の後も村には大量の武器が残ったと論じた（『刀狩り』岩波新書、2005年）。 | `[A]` |
| **熊手** | 『平家物語』の「弓流し」の場面に、船の上で熊手を使って引っかける描写がある。鉤で引っかけて引き倒す道具は、中世の軍記によく出てくる。 | `[B]` ※要原典照合（本文） |
| **掛矢**（大きな木槌）での門破り | 城門を破るのに使われたという説明はある。ただし典拠は百科事典サイトだけで、戦国期の実例は確かめられなかった。戸を破った例として有名なのは、江戸期の赤穂浪士の討ち入り（元禄15年＝1702年）。 | `[B/C]` ※要原典照合 |
| **鎌・竹槍による落ち武者狩り** | 広く語られている話だが、典拠は確かめられなかった。 | `[C]` ※要原典照合 |
| **斧・鉞・大槌を武器として使った戦国期の記録** | 今回は見つからなかった（§1-3）。 | ― |

**時代像として押さえておくこと**
1560年代の村は武装しているのが普通でした。「道具しか持たない無力な農民」というイメージは、刀狩より後の時代のものです。職人や百姓が自分の道具で身を守ったり、雇われて戦いに加わったりするのは、この作品の時代設定とよく合います `[A→D]`。

**スキル設計の案** `[D]`
1. **道具の転用を仕組みにする**
   - 生産スキル（系統10〜16）の道具は、そのまま戦闘にも使えるようにする。
   - ただし正式な武器に比べて、間合い・振り直しの速さ・耐久のどれかが劣るようにする。
   - 一方で、荒魂の外殻を割る力や地形を変える力など、道具ならではの長所を持たせる。

   | 道具 | 主な使い手（系統） | 属性 | 道具ならではの効果 |
   | :--- | :--- | :--- | :--- |
   | 掛矢・大槌 | 番匠（11）・杣人（11） | 打撃・崩し | 門・柵・岩を壊す。外殻を割るボーナス。 |
   | 手斧・釿 | 番匠（11）・木地師（11） | 切断 | 逆茂木や障害物を切り払う。 |
   | 鶴嘴・鏨 | 金掘り・鍛冶（10） | 貫通・崩し | 坑道を掘る。岩の外殻を貫く。 |
   | 黒鍬の鍬・鋤 | 百姓（15） | 崩し | 堀や土塁を作り、足場を変える。 |
   | 鎌・熊手 | 百姓（15）・杣人（11） | 切断・崩し | 足を払う。引き倒す。 |
   | 向こう鎚 | 鍛冶（10） | 打撃 | 金属の外殻をへこませる。 |

2. **城攻めを生産スキルの見せ場にする**
   - 坑道を掘る、門を破る、堀を埋める、舟橋を架けるといった作業を、それぞれ生産スキルで解く試練にする。
   - モデルは白鹿城の坑道戦。地下で敵の坑道とつながったときに戦闘が始まる、という流れにすると史実と重なる。
3. **系統2の金砕棒・大槌の位置づけを直す**
   - 大槌は、掛矢や工兵の道具が戦いに転じたものと説明する（§1-3 の推奨をこの方向で更新）。
   - 金砕棒は、これまでどおり荒魂退治のための神事の打撃具 `[D]` とする。
4. **二つ名や隠し職とつなげる**
   - 戦闘スキルと生産スキルの組み合わせで二つ名が生まれる仕組み（`skills_16_lines.json`）に、道具の転用を足す。
   - 例：番匠＋長柄 →「門破り」、金掘り＋組討 →「穴掘り武者」、百姓＋長柄 →「地侍」。

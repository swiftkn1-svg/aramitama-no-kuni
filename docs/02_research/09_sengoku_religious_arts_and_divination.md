# 補遺8：戦国期（1550〜1570年代）神道・陰陽道・仏教密教の法術と、暦注・占術の時代考証

> **目的**: 戦闘スキル系統7「神道祭祀」・系統8「仏門法術・僧兵」・系統9「陰陽道・天文」に、時代考証の裏づけを付けます。あわせて、戦闘では直接使わない占い・暦注・天文の知識も集めました（生活系・イベント系で使う想定）。
> **証拠区分**: `[A]` 一次史料・定説 / `[B]` 軍記・覚書・後世の記録 / `[C]` 伝承・民俗 / `[D]` ゲーム的翻案
> **表記**: 【Web確認】＝今回Web上の辞典・研究機関の資料で確かめた項目。「※要原典照合」＝まだ原典で確かめていない項目。
> **関連資料**: 01（起請文・飯縄信仰・陰陽師の職人歌合）、05（四分野の役割比較・不動護摩）、06（永禄6年の日食）、08（軍配者の実像・足利学校）。重なる部分はそちらを参照し、ここでは繰り返しません。

## §0 結論（先に要点）

1. **担い手の勢力図が、ちょうどこの時代に変わっています**。
   - 神道は、吉田家（吉田神道）が神祇伯の白川家と張り合い、全国の神社に勢力を広げていた時期です `[A]`。
   - 陰陽道は、暦を担当した賀茂氏の勘解由小路家が**永禄8年（1565）に絶えました** `[A]`。残った安倍氏の土御門家が、陰陽道と暦の両方を受け継いでいきます。
   - 修験道は、本山派（天台系）と当山派（真言系）に分かれてはいました。ただし、幕府が山伏を統制するのは慶長18年（1613）からで、戦国期の山伏はまだ自由に国々を渡り歩けました `[A]`。
2. **法術の多くは、平安・鎌倉期からあるものが続いています**。祓・護摩・反閇・方違え・九字などです。戦国期の発明ではありませんが、戦国期に使っても問題ありません。
3. **暦注・占いは、使えるものと使えないものの差が大きい分野です**。
   - **六曜**（大安・仏滅など）は、名前も使い方も今とは違いました。日の吉凶を見るようになるのは江戸後期です。
   - **九星・家相・手相・人相見**は、広まるのが江戸以降です。
   - 戦国期の暦に実際に書かれていたのは、**干支・十二直・二十七宿・方位神**などです。

## §1 神道系の法術（系統7「神道祭祀」）

### 1-1 担い手：吉田家と白川家

- **吉田神道（唯一神道）** `[A]`【Web確認】
  - 京都・吉田神社の神職、吉田兼倶（1435–1511）が始めました。戦国期に生まれた神道の一派です。
  - 主な著作は『唯一神道名法要集』『神道大意』『中臣祓抄』です。
  - 「神が本体で、仏はその仮の姿」とする考え方（反本地垂迹説）を唱えました。道教の影響も指摘されています。
  - **宗源宣旨**: 吉田家が諸国の神社に、神の位や神号を独自に与えた文書です。最初は朝廷の関わらない私的な文書でしたが、吉田家の勢力が大きくなるにつれ、公的な文書のように扱われていきました。
- **白川家（神祇伯）** `[A]`: 朝廷の神祇官の長を代々務めた家です。吉田家とは、神職の世界の主導権を争う関係でした。
- **ゲームへの示唆** `[D]`
  - 地方の神社が「吉田家から神号をもらいたい」と望むクエストが作れます。宗源宣旨を京へ取りに行く、という流れです。
  - 系統7の師匠NPCを「吉田流」と「白川流」の二系統に分けると、どちらに入門するかを選ぶ場面が生まれます。

### 1-2 祓・清め

| 法術 | 内容 | 区分 | ゲームでの使い方 |
| :--- | :--- | :--- | :--- |
| **中臣祓（大祓詞）** | 罪や穢れを祓う祝詞。兼倶が注釈書『中臣祓抄』を書いた | `[A]` | 系統7の基本技（穢れ解除） |
| **禊（みそぎ）** | 水を浴びて身を清める | `[A]` | 戦闘前の準備行動 |
| **湯立（ゆだて）** | 釜で湯を沸かし、笹で湯を振りかけて清め、神意を伺う | `[A/C]` | 範囲浄化。託宣イベントの入口 |
| **鳴弦・蟇目（ひきめ）** | 弓の弦を鳴らす、または穴の空いた鏑矢を射て音を立て、魔を祓う。平安期から宮中・武家の作法 | `[A]` 戦国期の具体例は※要原典照合 | 系統7の「梓弓」とつながる。音で怪異を退ける |
| **神楽・託宣** | 巫女や神職が神がかりして、神の言葉を伝える | `[A/C]` | 情報収集（ヒント入手） |

### 1-3 神判（神に真偽を問う裁き）【Web確認】

- **湯起請（ゆぎしょう）** `[A]`: 熱湯の中から小石を拾い出させ、手のやけどの具合で、言い分が本当かどうかを決めます。史料では、15世紀（室町中ごろ）の例がいちばん多いとされます。
- **鉄火（火起請）** `[A]`: 真っ赤に焼いた鉄を握らせて決めます。戦国期には湯起請に代わってよく使われるようになりました。戦国末から江戸初めには、村どうしの境目の争いで決着がつかないときに、たびたび行われています。
- **起請文と牛玉宝印**: 01 §3 を参照してください。
- **ゲームへの示唆** `[D]`
  - 境目争い（山・用水・入会地）のクエストで、神判を試練の一つとして使えます。
  - マルチ解法試練の候補になります。たとえば「神判で決める」「証拠を集めて話し合いで決める」「荒魂を鎮めて争いの原因そのものを無くす」の3通りです。

## §2 陰陽道の法術（系統9「陰陽道・天文」）

### 2-1 担い手の状況：永禄8年の断絶【Web確認】

- **賀茂氏・勘解由小路家の断絶** `[A]`
  - 永禄8年（1565）、勘解由小路在富が跡継ぎのないまま亡くなりました。これで、中世に暦を担当してきた賀茂氏は、実質的に絶えました。
  - 家に伝わった記録の一部は土御門家に移りましたが、多くは失われたとされます。
  - 出典: 末柄豊「勘解由小路家の所領について」（東京大学史料編纂所）。
- **安倍氏・土御門家** `[A]`
  - 若狭国名田荘（現在の福井県おおい町）などに所領を持っていました。
  - 戦国期に一族が名田荘にどの程度住んでいたかは、まだ確かめていません ※要原典照合（おおい町教育委員会編『土御門家陰陽道の歴史』）。
- **民間の陰陽師** `[A]`: 唱門師（声聞師）と呼ばれた人々が、町や村で祈祷・占い・暦売りをしていました。職人歌合に「陰陽師」が描かれています（01 §3 参照）。
- **ゲームへの示唆** `[D]`: 1565年は、出雲編（永禄5〜9年）の期間中です。
  - 「賀茂家の暦の秘書が散らばり、各地に流れた」という設定にできます。
  - 系統9の伝書（08 §2）を集める動機として、そのまま使えます。

### 2-2 主な術

| 術 | 内容 | 区分 | ゲームでの使い方 |
| :--- | :--- | :--- | :--- |
| **反閇（へんばい）** | 特別な足の運びで大地を踏み、邪気を払う | `[A]` | 地面に作用する結界（要釘の打ち込みとつなげる） |
| **身固め** | 体に呪を施して守る | `[A]` | 単体防御バフ |
| **方違え・物忌** | 凶の方角を避けて回り道する／家にこもって身を慎む | `[A]`（平安期に盛ん。戦国期の実例は※要原典照合） | 移動ルートの選択（凶方位に行くと荒魂の遭遇が増える等） |
| **泰山府君祭** | 寿命を延ばし、災いを除く祭り | `[A]` | 蘇生・延命系の大技（使う回数を制限） |
| **式占（六壬式盤）** | 回転する盤で吉凶を占う | `[A]` | 系統9の「式盤」。敵の弱点・出現方角の看破 |
| **呪符** | 「急急如律令」などを書いた札 | `[A/C]` | 系統9の「五色護符」 |
| **九字** | 「臨兵闘者皆陣列在前」。出典は東晋の葛洪『抱朴子』で、山に入るときに唱える呪文だった。手で印を結んだり、縦横に空を切ったりする作法は後の時代に加わった。日本では修験道・陰陽道で身を守る呪文として使われた | `[A]`【Web確認】 | 系統7・8・9の共通技。忍びの印というイメージは後世のもの |

### 2-3 暦そのもの【Web確認】

- **宣明暦** `[A]`: 貞観4年（862）から貞享暦に変わるまで（1684年）、823年間使われました。つまり戦国期を通して、暦の計算方法は一つです。
- **地方暦** `[A]`
  - 南北朝のころから、朝廷の暦が地方に届きにくくなりました。そのため各地で、かなで書いた暦が作られるようになりました。
  - **三島暦**（伊豆・河合家）: 最も古い記録は1374年（義堂周信『空華日工集』）で、京の暦と1日ずれていたことが書かれています。
  - **丹生暦**（伊勢）: 享禄5年（1532）には存在していた記録があります。
  - **南都暦**（奈良）などもありました。
  - 同じ宣明暦でも、計算する人が違うと誤りが出て、**地方暦どうしで日付が違う**ことがありました。
- **ゲームへの示唆** `[D]`
  - 「村の祭りの日が、隣の国の暦と1日ずれている」というクエストが作れます。系統9の「暦算」で正しい日を割り出すと、祭りが成立して結界が回復する、という流れです。
  - 06 の日食（1563年）と組み合わせると、「暦が日食を予告できたかどうか」で日食の予知力に差を付けられます。

## §3 仏教・密教の法術（系統8「仏門法術・僧兵」）

### 3-1 密教（真言宗＝東密、天台宗＝台密）

- **護摩の種類** `[A]`: 目的によって炉の形や色、本尊が変わります。
  - **息災**: 災いを除く。
  - **増益**: 福を増やす。
  - **調伏**: 敵や悪いものを退ける。
  - **敬愛**: 人と和合する。
  - これに**鉤召**（人や物を呼び寄せる）を加えて五種とする数え方もあります。
  - 不動護摩については 05 §3 を参照してください。
- **五壇法** `[A]`【Web確認】: 五大明王を五つの壇で同時にまつる、大がかりな修法です。室町幕府は、京都の門跡寺院（特に醍醐寺三宝院）を動かして、武家を守るための加持祈祷を行わせていました（『史学雑誌』130編12号、2021年の論文）。
- **加持と香水（こうずい）** `[A]`【Web確認】: 密教では、香を混ぜた清い水（香水）を真言で加持し、散杖（さんじょう）という杖の先でかき回してから、壇・供物・行者自身に注いで清めます。この作法を洒水（しゃすい）と呼びます。護摩のような大がかりな壇を使わない、基本の清めの作法です。
- **四度加行（しどけぎょう）** `[A]`【Web確認】: 真言宗で、伝法灌頂を受ける前に行う四段階の修行です。十八道・金剛界・胎蔵界・護摩の四つです（順序は法流によって違います）。護摩はこの加行の一つに数えられるので、修行を積んだ僧が修める作法だと言えます。
- **戦国大名が敵国の調伏を祈らせた具体例**は、今回は見つかりませんでした ※要原典照合。
  - 武田・上杉などが寺社に願文を納めた例はあります（01 §3）。そこに調伏の文言があるかどうかは、個別に確かめる必要があります。
- **ゲームへの示唆** `[D]`
  - 系統8の「護摩火」を、息災・増益・調伏・敬愛の4つに分けて習得させます。
  - 調伏は荒魂への攻撃、敬愛は和魂化（説得）の補助、という分け方ができます。
  - 習得の順は、加持（Lv25）を先に置き、護摩（Lv40 以降）を後に置きます。四度加行で護摩が後の段階に置かれていることに合わせた並べ方です。数珠（念珠）を摺る所作を加持の技に含めるのは、ゲーム上の整理です。

### 3-2 修験道（山伏）【Web確認】

- **二つの派** `[A]`
  - **本山派**: 天台系。聖護院が総本山で、熊野の山伏の流れをくみます。
  - **当山派**: 真言系。室町中期ごろから醍醐寺三宝院の下に入りました。
- **統制の始まり** `[A]`: 慶長18年（1613）、徳川家康が聖護院と三宝院に「山伏法度」を出しました。江戸時代には全国の山伏がどちらかの派に属させられ、渡り歩くことを禁じられて、町や村に住むようになります。
  - **つまり戦国期の山伏は、まだ自由に国々を渡り歩いていました**。漂泊者としての山伏を出しても問題ありません。
- 大峰の奥駈けなど修行の内容は、05 §3 を参照してください。

### 3-4 呪術を使わない宗派・使う宗派

- **浄土真宗（一向宗・本願寺）** `[A]`
  - 阿弥陀仏にすべてを任せる教えのため、祈祷やまじないは本来退けます。
  - 石山合戦などでは、門徒（根来衆とは別に、雑賀衆など）が大名と戦いました。
  - **ゲームへの示唆** `[D]`: 法術は使わないが、信心による精神耐性（恐怖・混乱に強い）を持つ集団として描くと、史実と矛盾しません。
- **時衆（時宗）の陣僧** `[B]`: 合戦に付き従い、死にゆく者に念仏（十念）を授け、遺体を弔ったとされます。南北朝・室町期の例が知られていますが、今回のWeb検索では裏付けが取れていません ※要原典照合。
- **日蓮宗（法華宗）** `[A]`: 題目と法華経による祈祷を行います。京の町衆に信者が多い宗派でした。
- **禅宗** `[A]`: 葬送や外交で大きな役目を持っていました。毛利家の外交僧・安国寺恵瓊が代表例で、出雲編の時期とも重なります（恵瓊が外交の表舞台に出る時期は※要原典照合）。

## §4 戦場まわりの儀礼（戦闘には直接関わらないが、戦の前後に行うもの）

- **出陣の三献** `[A/B]`【Web確認】
  - 打鮑（敵を「討つ」）・勝栗（「勝つ」）・昆布（「よろこぶ」）の三品を、酒と交互にいただき、最後に鬨の声を上げます。
  - 順番は、打鮑→酒→勝栗→酒→昆布→酒→鬨の声、です（松江市の資料にある再現例）。
  - もとは式三献という作法から来ていて、今の三三九度もその流れです。
  - 出陣前に白い衣を着て、肉や魚・酒を断ち、水で身を清める、という慣習も伝わっています。どの家で行われていたかは※要原典照合。
- **日取り・方角・軍神の勧請**: 08 §3（軍配者の実像）を参照してください。
- **首実検の細かい作法**: 江戸時代の軍学書で整えられた部分が多いので、戦国期そのままの姿かどうかは※要原典照合です。

### 5-3 天文と天変

- **天変は政治の出来事でした** `[A]`【Web確認】
  - 彗星・日食・月食・地震などは「天からの警告」とされ、元号を変える理由になりました（災異改元）。
  - 天正への改元（1573年）は、戦乱（兵革）を断ち切るための改元とされています。
  - 『信長公記』の彗星の記事は、今回は確かめていません ※要原典照合。
- **日食**: 06 §4（1563年の日食）を参照してください。
- **時刻** `[A]`: 昼と夜をそれぞれ六つに分ける不定時法で、季節によって一刻の長さが変わりました。十二支で時刻を呼びました（子の刻、丑の刻など）。
  - **ゲームへの示唆** `[D]`: 「丑の刻だけ現れる荒魂」のように、時刻を十二支で管理すると雰囲気が出ます。夏と冬で一刻の長さが変わる、という細かい再現もできます。

## §6 ゲーム設計への提案 `[D]`

1. **生活系に暦注を入れる**: 十二直と二十七宿を、日ごとの補正として使います（例：「成」の日は普請の成功率が上がる、「破」の日は戦向き）。六曜と二十八宿は時代に合わないので使いません。
2. **地方暦のずれクエスト**: 三島暦と京の暦が1日ずれている、という史実をもとにします。系統9の「暦算」で正しい日を割り出すと、祭りが成立して結界が回復します。
3. **永禄8年の賀茂家断絶イベント**: 散らばった暦の秘書を集めると、系統9の伝書（目録→絵目録→印可状、08 §2）が手に入ります。師匠NPCの段階上限（70→85→100）と連動させます。
4. **護摩の四種分岐**: 系統8を、息災（回復）・増益（強化）・調伏（攻撃）・敬愛（和魂化の補助）に分けます。
5. **神判を試練に**: 境目争いで、湯起請・鉄火を、マルチ解法試練の選択肢の一つにします（他の解き方は、証拠集め・荒魂を鎮めること）。
6. **神道の二流派**: 系統7の入門先を、吉田流（神号・宣旨を扱う）と白川流（朝廷の祭祀を扱う）から選ばせます。
7. **漂泊の山伏**: 1613年の統制より前なので、山伏NPCは国境を越えて自由に動けます。情報屋や、霊山（04）への案内役に向いています。

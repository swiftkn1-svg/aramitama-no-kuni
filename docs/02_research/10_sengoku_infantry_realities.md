# 補遺9：戦国期の足軽・雑兵の実態 ―「一般人卒業（Lv50）」の境界線

> **目的**: スキル16系統の Lv0〜50（誰でも取れる基礎領域）で、「素人が一人前の足軽・野武士になった」と言える線を、史料にもとづいて決めます。
> **証拠区分**: `[A]` 一次史料・同時代記録 / `[B]` 軍記・江戸前期の回想記や教訓書（『雑兵物語』『おあむ物語』など） / `[C]` 口伝・俗説 / `[D]` ゲーム的な境界線の提案
> **表記**: 【Web確認】＝今回Web上の資料で確かめた項目。「※要原典照合」＝まだ原典で確かめていない項目。
> **関連資料**: 07（負傷統計・槍は「叩く」・刀狩）、08（流派武芸は口伝中心で、江戸期に体系化）。

---

## §0 結論（先に要点）

1. **足軽にとっての「一人前」とは、技の上手さより、隊列の中で生き残る作法を身につけていることでした。**
   - 『雑兵物語』の古参たちが新米に教えるのは、刃筋や受け流しの話ではありません。「穂先をそろえて上から叩け」「深追いするな」「慌てて撃つな」「兵糧と水を切らすな」といった内容です `[B]`【Web確認】。
2. **「腰を落として刃筋を通す」「受け流す」は、Lv50より上（師事・流派の領域）に置いて構いません。**
   - 戦場での負傷の大半は、矢・鉄砲・石・槍によるものでした。刀による傷は全体の数％です（07 §1）。足軽が刀で斬り合う場面は、そもそも多くありません `[A]`。
   - 『雑兵物語』も、足軽の安物の刀は鎧に当たると曲がると書いています。だから「鎧のない手足を狙え」という教えになります `[B]`【Web確認】。
3. **武器が壊れたときの直し方は、史料がほとんど残っていません。**
   - 確かめられたのは、「手入れを怠った槍が戦場で壊れた」という失敗談が1件だけです `[B]`。
   - 陣中での研ぎ直しや曲がり直しの具体的な記録は見つからなかったので、ゲーム側の提案（`[D]`）として扱います。

### 史料についての注意

- **『雑兵物語』** `[B]`【Web確認】
  - 成立は1657〜1683年の間とされ、作者ははっきりしていません（松平信興の作とする説、松平輝綱の作とする説があります）。刊行されて広く読まれたのは1846年です。
  - 島原の乱（1637〜38年）のあと、実戦を知る者が減っていく時期に書かれました。戦国期そのものの記録ではなく、**江戸前期に戦場の知恵をまとめた教訓書**として読むのが妥当です。
  - 形式は、鉄砲足軽・弓足軽・槍持ち・馬取り・荷運びなど30人あまりの雑兵が、自分の体験を語るというものです。
- **『おあむ物語』** `[B]`【Web確認】
  - 関ヶ原の戦い（1600年）のとき大垣城に籠城した、石田三成の家臣の娘が老後に語った話です。本人が書いたものではなく、話を聞いた親族の子が書き留めたものと考えられています。
  - 天守で、味方が討ち取った首を整える場面などがあります。

## §1 素人・新米がやらかす典型的な失敗

### 1-1 史料に出てくる失敗（『雑兵物語』より）`[B]`【Web確認】

| 失敗 | 内容 | 語り手 | 教訓 |
| :--- | :--- | :--- | :--- |
| **刀が曲がる** | 足軽の安物の刀は、重い鎧に打ち当てると「鍋の柄のように」曲がる | （観光庁の多言語解説による要約。どの語り手の言葉かは※要原典照合） | 鎧で守られていない手足を狙う |
| **手入れ不足で槍が壊れる** | 主人の持槍を担いだまま眠ってしまい、柄の端の金具（逆輪）を盗まれた。そのまま馬の腹に突き込んだら柄が割れ、穂先の根元が引っかかって抜けず、穂先を敵にひったくられた | 持槍担ぎ・吉内左衛門 | 武具の金具一つが、命に関わる |
| **足をすべらせて転ぶ** | 手負いの騎馬武者の馬を突いたとき、足がすべって転び、鼻を打って鼻血を出した（馬も倒れ、敵は落馬した） | 同上 | 突いた後の体勢まで考える |
| **首を取るのに手間取る** | 倒れた敵の首を大脇差で取ろうとして苦労した | 同上 | 具足の上に小脇差（1尺3寸未満）を差しておくとよい |

| **兵糧袋の結び目を胸に作る** | 首にかける兵糧袋（数珠打飼袋）の結び目が胸に来ると、鉄砲の狙いがつけられない | 同上 | 結び目は襟の後ろの真ん中にする |
| **梅干しをなめてしまう** | なめたり食べたりすると、かえって喉が渇く | 同上 | 息が切れたときに「見る」だけにする。出てきた唾を飲む |
| **唐辛子の手で目をこする** | 寒さしのぎに、すりつぶした唐辛子を尻から足先まで塗る。その手で目をいじると、目が血走って痛む | 同上 | 塗った手で顔にさわらない |
| **深追いする** | 敵を崩しても、一町（約109m）より先まで追うと、はぐれたり、思わぬ反撃を受けたりする | 槍担ぎ小頭・長柄源内左衛門 | 旗や馬印のもとに固まって守る |
| **多人数の場で槍を突く** | 大勢の合戦で、ばらばらに突いてしまう | 同上 | 穂先をそろえ、拍子を合わせて上から叩く。突くのは一対一の出会い頭だけ |

### 1-3 古参が新米にまず教えたこと（まとめ）

『雑兵物語』の語りから拾うと、内容は大きく3つに分けられます `[B]`。

1. **隊から離れない**: 穂先をそろえる。拍子を合わせる。深追いしない。旗のもとに固まる。
2. **狙う場所を間違えない**
   - 鎧のない手足を狙う。
   - 騎馬武者は、まず馬を狙う（鉄砲も槍も同じ）。乗り手を失った馬は暴れて、敵陣をかき回すことがある。
3. **体を持たせる**
   - 兵糧袋は一食分ずつ縛っておく。
   - 梅干しは見るだけにする。
   - 喉が渇いたら、濁った水の上澄みをすする（死人の血でもすすれ、とまで言っている）。
   - 寒いときは唐辛子を足に塗る。馬糞を燃やして火を起こす。

そのほか、鉄砲の射程の目安は約100mとされています（観光庁の多言語解説による要約）`[B]`。

## §2 「一般人卒業」の到達点

### 2-1 足軽という身分の実態 `[A]`【Web確認】

- 領主が自分の領地の百姓を武装させて連れて行くのが、もともとの形でした。
- 戦国期にはそれでは足りなくなり、渡り歩く雇われ兵も加わりました。
- 足軽は武士と違って、逃げることを恥としませんでした。そのかわり、集団で戦うことを得意としました（コトバンク「足軽」）。
- 戦国大名は足軽を組に分けて組織し、鉄砲が広まると、武器ごとの組（鉄砲組・弓組・長柄組）を作りました。
- 足軽の調練（集団訓練）の具体的な記録は、今回は見つかりませんでした ※要原典照合。
  - 候補になる文献は、西股総生『戦国の軍隊』と、講談社文庫『【絵解き】雑兵足軽たちの戦い』です。

### 2-2 武器ごとの「合格ライン」

流派を学んでいない兵が、場数を踏んで身につける到達点です。

| 武器 | 合格ライン（これができれば犬死にしない） | 根拠 |
| :--- | :--- | :--- |
| **長柄** | 組の中で穂先をそろえ、合図に合わせて上から叩ける。崩れた敵を深追いしない。騎馬武者には馬の腹を突く | `[B]` 長柄源内左衛門の語り |
| **鉄砲** | 落ち着いて狙い、無駄弾を撃たない。射程の目安（約100m）を守る。馬を先に撃つ | `[B]` 朝日出右衛門の語り |
| **刀・脇差** | 刀は主に首を取るためと、とどめを刺すために使う。斬るなら手足を狙い、鎧は打たない。首を取りやすい小脇差を差しておく | `[A]` 負傷統計（07）、`[B]` 吉内左衛門の語り |
| **組討** | 倒れた敵・落馬した敵に乗りかかり、短い刃物で首を取る。鎧の隙間を刺す鎧通しはここで使う（07） | `[B]` |
| **全般** | 兵糧・水・寒さを自分で管理できる。持たされた武具の金具や紐の傷みに気づける | `[B]` |

### 2-3 「腰を落として刃筋を通す」「受け流す」はどこに置くか

- これらは、08 で見た**流派武芸（新陰流など）の領域**です。
  - 戦国期の流派は、師から弟子へ口伝で伝わるもので、学べるのはごく一部の武士だけでした（08 §0）。
- 足軽の教訓書には、こうした体の使い方の話はほとんど出てきません。
  - 語られているのは、「どこを打つか」「いつ打つか」「隊列のどこにいるか」だけです `[B]`。
- **提案** `[D]`
  - Lv0〜50 は**「場数で覚える戦場作法」**とします。
  - Lv50 を超えたら**「師事で学ぶ体の技」**に切り替えます。
  - こうすると、師匠NPCの段階上限（70→85→100）とも、きれいにつながります。

### 2-4 Lv0〜50 の段階案 `[D]`

| Lv | 呼び名 | 状態 | 主に覚える作法 |
| :--- | :--- | :--- | :--- |
| 0〜9 | 素人 | 武器を持たされただけの百姓・町人 | 失敗表（§1）がそのまま発生する（転ぶ・空振り・無駄弾・目をこする） |
| 10〜24 | 見習い（陣夫・小荷駄） | 荷運びや槍持ちとして戦場に出る | 兵糧・水・寒さの管理。主人の武具の手入れ（逆輪や紐の点検） |
| 25〜39 | 新参の足軽 | 組の一員として戦える | 穂先をそろえて叩く。合図に合わせる。落ち着いて撃つ |
| 40〜49 | 古参の足軽 | 新米に教えられる | 深追いしない判断。馬を先に狙う。手足を狙う |
| **50** | **一人前（一般人卒業）** | **足軽・野武士として生き残れる** | **首を取る手順。小脇差の備え。壊れた武具をその場でしのぐ（§3）** |

- **Lv50 の解禁演出案** `[D]`: 「古参に『もう教えることはない』と言われる」「新米を一人預けられる」など。
- **Lv50 での失敗率** `[D]`: 失敗表のイベントがほぼ起きなくなる、という形で「卒業」を体感させます。
- **系統ごとの読み替え** `[D]`
  - 生産系（系統10〜16）では、同じ考え方で「一人で仕事を任される職人（一人前）」を Lv50 とします。
  - 霊威系（系統7〜9）では、「祭りや祈祷の手伝いを任される」ところを Lv50 とします。

## §3 武器の損耗と手入れ

### 3-1 史料で確かめられたこと

- **刀は鎧に当たると曲がる** `[B]`【Web確認】: §1-1 のとおりです。
- **槍は金具一つで壊れる** `[B]`【Web確認】: 逆輪（柄の端を締める金具）がないと、突いた衝撃で柄が割れます。
- **刀は研ぎ直されて形が変わる** `[A]`: 研ぎ直しを重ねて、刀の形や刃文が変わったものが残っています。ただし、陣中で研いだ記録は見つかっていません。
- **刀狩（1588年）** `[A]`: 百姓の手元にも刀があったことの裏返しです（07 §4-4）。

### 3-2 確かめられなかったこと（※要原典照合）

| 項目 | 現状 | ゲームで使う場合 |
| :--- | :--- | :--- |
| 曲がった刀を足で踏んで直す | 今回は史料が見つからなかった | `[C]`。「荒っぽい応急処置」として使えるが、史実とは書かない |
| 陣中に鍛冶や研ぎ師がついて行った | 未確認 | 陣中鍛冶の NPC を出すなら `[D]` と明記 |
| 足軽が砥石を持ち歩いた | 未確認 | `[D]` |
| 折れた槍の柄を、縄や竹で継いで使った | 未確認 | `[D]`。系統11「伐採・木工」の応急技にできる |
| 長柄の柄は、竹を張り合わせて作った（打柄） | 一般にそう言われるが未確認 | 確認できれば、系統11・12で作れる素材にする |

### 3-3 ゲームへの提案 `[D]`

1. **耐久の減り方を武器で変える**: 刀は「鎧を打つ」と大きく減り、手足を打つと減りにくくします。プレイヤーが自然に「手足を狙う」ようになります。
2. **金具の点検**: 槍の逆輪のような小さな部品が壊れると、武器が使えなくなります。Lv10〜24 の見習いの仕事として点検を入れます。
3. **応急処置と本修理を分ける**
   - 戦場では、縄で巻く・竹で継ぐなどの応急処置しかできません（系統11・12の Lv50 技）。
   - 町や村では、鍛冶（系統10）が本格的に直します。
   - こうすると、生産系と戦闘系を行き来する理由が生まれます。
4. **首取り用の小脇差**: 戦闘系の Lv50 で「小脇差を差しておく」作法を覚えると、組討で首を取る速さが上がります。

## §6 ゲーム化の提案（対人・対荒魂の両立）`[D]`

> オーナー・アルテ・Claude Code の三者で合意した設計方針です（2026-11-08）。§1〜§3 の史実を、怪異（荒魂）との戦いにも使える形に読み替えています。次の段階で `combat_5_attributes.json` と `skills_16_lines.json` に展開します。
>
> **改訂注記（2026-11-11・オーナー決定）**
> - 卒業技（二の太刀＋気脈見切りなど）は **Lv45** に置きます。拍子判定の三拍子（120ms）も Lv45 で届きます。
> - **Lv50 は、系統ごとに別の全職共通パッシブを1つ得る節目**とします。大きさは「素人卒業」（不慣れの不利が消える程度）で、行動のしやすさを中心にします。刃こぼれ半減などの強い効果は Lv51 以上に置きます。
> - この文書で「Lv50 の技」「Lv50 で覚える作法」と書いている箇所（§2-4・§3-3 を含む）は、Lv45 の卒業技までに覚えるものと読み替えてください。
> - 最新の値は `data/skill_lines.json`（旧 `skills_16_lines.json`）にあります。

### 6-1 基本方針

- **どの武器も、どの属性にも手を出せる。ただし、一番効率がよいのは本職の武器。**
  - 武器種ごとに基本の性格（重さ・間合い・手数）を決めます。
  - そのうえで、モーションごとに属性の配分を変えます。
  - こうすると、刀で峰打ちができても大槌の役目は奪わず、一人で遊ぶ自由と、武器の持ち替えや仲間との連携の面白さが両立します。
- **戦闘系の腕前からは霊威を出さない。**
  - 戦闘系（系統1〜6）だけでも荒魂は倒せます。ただし、鎮めて和魂に戻すことはできません。
  - 鎮めるには、系統7〜9の法術、銘入りの刀（生産系・御番鍛冶）、清めの塩や神酒が要ります。
  - 拠り所 `[B/C]`
    - 鵺退治：源頼政が弓で射落とし、猪早太が刀でとどめを刺した（『平家物語』）。一つの武器でなく、役目を分けて倒している。
    - 大百足退治：俵藤太は、刀ではなく唾をつけた矢で倒した。
    - 土蜘蛛・鬼の腕：斬れたのは名刀（膝丸・髭切）の力だった。怪異に効く霊威は、刀そのものから来ている。

### 6-2 攻撃一回ごとに持つ3つの値

| 値 | 意味 | 効くところ | 史実の拠り所 |
| :--- | :--- | :--- | :--- |
| **属性配分** | そのモーションが、5属性（打撃・切断・貫通・崩し・霊威）を何割ずつ持つか。例：切断8・打撃2 | ダメージの通り方 | — |
| **衝撃** | 一撃の重さ | 外殻を割る量、よろけ | 大太刀・長柄は重さで叩く `[B]` |
| **刃の負担** | 刃こぼれ・目釘のゆるみの溜まり方 | 武器の耐久 | 安物の刀は鎧に当たると曲がる（§1-1）`[B]` |

### 6-3 外殻ゲージ

- 荒魂（と鎧武者）は、**部位ごとに外殻ゲージ**を持ちます。泥鎧、百足の鋼殻、岩肌、甲冑などです。
- 外殻は、**打撃の割合 × 衝撃** の分だけ削れます。
- **外殻が残っている所を斬ると**、切断のダメージが大きく減り、刃の負担がはね上がります。
- **外殻が割れて肉や核が出ると**、切断と貫通のダメージが大きく上がります。
- 結果として次のような差が出ます。
  - 刀の峰打ちでも外殻は削れます。ただし衝撃が軽いので、何度も打ち込む必要があります。
  - 大槌なら数回で割れます。
  - 槍や弓は、割れた所から核を突くと一番よく効きます。
- **倒す順番の型**: 崩す・剥がす（打撃・崩し）→ 断つ（切断）→ 穿つ（貫通）→ 鎮める（霊威）。

### 6-6 刀剣系統 Lv0〜50 の手の解禁順（2026-11-11 改訂）

Lv0〜50 は「場数で覚える戦場の手」とします（§2-3）。刃筋を通す・受け流すといった体の技は、Lv51 からの流派の目録（08）に置きます。

| Lv | 手 | 対人 | 対荒魂 | 主な属性 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 打ち込み | 真っ向から振り下ろす | 柔らかい所には通る。外殻に当たると弾かれて刃こぼれする（失敗から覚える） | 切断 |
| 10 | 見切り | 鎧のない所が分かる | 部位の硬さが、叩いたときの音や色で分かる | （判別） |

| 25 | 拍子斬り | 胴丸の隙間を裂く連撃 | 剥がれた所を、拍子に合わせて深く裂く（タイミング判定。合うと快音と威力上昇） | 切断 |

- 他の系統も同じ形で作ります。たとえば長柄は、「叩く（打撃）→ 突く（貫通）」を軸にします。

### 6-7 達成感を足す仕掛け

1. **戦歴帳（軍忠状）と感状** `[A]`
   - 戦国の兵は、自分の手柄を軍忠状に書いて出し、褒美を受けていました。これを実績の仕組みにします。
   - 「初めて首を取った」「初めて泥鎧を割った」などが記録されます。
   - 節目では、NPCから感状（褒め状）がもらえます。
2. **拍子判定** `[B]`: 「拍子を合わせて叩け」を、ボタンを押すタイミングの判定にします。レベルが上がると判定の幅が広がり、二拍子・三拍子も刻めるようになります。
3. **失敗が消えていく演出**: §1 の失敗表（転ぶ・空振り・弾かれる・無駄弾）を序盤に実際に起こし、レベルとともに減らします。減ったことはログやNPCの一言で知らせます。
4. **手ごとの熟練**: 同じ手を使い込むと「覚えた → 身についた → 冴え」と段階が上がり、音・振りの速さ・手応えが変わります。
5. **手に馴染む刀**: 同じ一振りを使い続けると、相性の補正が付きます。鍛冶（系統10）が打った銘入りの刀とつながります。

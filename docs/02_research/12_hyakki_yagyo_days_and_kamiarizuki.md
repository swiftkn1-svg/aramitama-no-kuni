# 補遺11：百鬼夜行日（忌夜行）と出雲の神在月 ―「荒魂が動く夜」を暦で決めるための時代考証

> **目的**: 百鬼夜行がいつ起きるかを暦で決める案（`data/combat_5_attributes.json` の `impurity_curse_and_hyakki_yagyo_2026_11_14`）に、時代考証の裏づけを付けます。あわせて、旧暦10月（神無月・神在月）が出雲でどう扱われていたかを確かめます。
> **証拠区分**: `[A]` 一次史料・定説 / `[B]` 説話・縁起・後世の記録・神社の公式説明 / `[C]` 伝承・民俗 / `[D]` ゲーム的翻案
> **表記**: 【Web確認】＝今回Web上の事典・研究機関・自治体・神社の資料で確かめた項目。「※要原典照合」＝まだ原典で確かめていない項目。
> **関連資料**: 04（鬼門守護）、06 §4（永禄6年の日食）、09 §2-3・§5-1（宣明暦と暦注）・§5-3（天変）。企画書 7-2（百鬼夜行の標的と攻め口）・10-4（新月と日蝕）。
> **今回の限界**: 読めたのは事典、研究報告の概要、自治体と神社の公開ページまでです。『拾芥抄』などの原典には当たっていません。

## §0 結論（先に要点）

1. **百鬼夜行日は、暦で決まった忌み日です** `[A]`【Web確認】。月ごとに十二支の日が決まっていて、12日ごとに巡ります。
2. **戦国期には、重みが薄れていた可能性があります**。室町時代以降は次第に重んじられなくなった、と推測する研究があります（研究者の推測）。
3. **新月・日蝕と百鬼夜行を結びつける史料は、今回見つかりませんでした**。組み合わせるなら、本作の創作 `[D]` です。
4. **出雲の神在月は、中世には唱えられていました** `[A]`【Web確認】。佐太神社は、神在祭の次第が約500年前の記録とほぼ同じだと説明しています `[B]`。
5. **神在祭の間、土地の人は慎みました** `[B]`【Web確認】。歌舞音曲・喧騒・造作を控えています。
6. **留守神と、出雲に行かない神の伝えは、各地の民俗伝承です** `[C]`。戦国期にさかのぼるかは確かめられていません。

## §1 百鬼夜行日

### 1-1 日取り 【Web確認】

『拾芥抄』に「子子午午巳巳戌戌未未辰辰」とあり、月ごとの十二支を示すとされます `[A]`。

| 月 | 百鬼夜行日 |
| :--- | :--- |
| 正月・2月 | 子の日 |
| 3月・4月 | 午の日 |
| 5月・6月 | 巳の日 |
| 7月・8月 | 戌の日 |
| 9月・10月 | 未の日 |
| 11月・12月 | 辰の日 |

- 『拾芥抄』は、貴族に必要な知識を部門別にまとめた類書です。鎌倉時代中期に原型ができ、南北朝時代初期に洞院公賢が増補したとする説などがあります。現存する最古の写本は室町初期と推定されています。
- 10世紀の『口遊』にも関連する記載があるとされます ※要原典照合。

### 1-2 暦注「忌夜行」と、月の数え方 【Web確認】

- 具注暦の暦注に「忌夜行」があります `[A]`。
- 戦国期に使われていた宣明暦（09 §2-3）の暦注は、『大唐陰陽書』に拠るとされます。
- **月は節月で数えるのが基本だ、という指摘があります**。節月は、立春などの節気で区切る月です。科研費の研究課題（21K12858、研究代表者は崔鵬偉氏）の報告によります。
  - 従来の解釈の多くは『拾芥抄』に基づくが、辞書や注釈書のほとんどは節切りに触れていない、とされます。
  - 『大唐陰陽書』の現存諸本は16世紀以降の写本で、「忌夜行」の日取りが『口遊』『拾芥抄』と一致しない箇所がある、とされます。
  - その理由として、室町時代以降は「忌夜行」が次第に重んじられなくなったためではないか、と報告は述べています。これは研究者の推測です。
- 戦国期の暦に「忌夜行」が実際に書かれていたかは、確かめていません ※要原典照合。

### 1-3 その日の慎みと、身を守る手立て

- **慎み** `[B]`【Web確認】: 百鬼夜行に遭うと死ぬとされ、その日は貴族が夜の外出を控えたといいます。
- **尊勝陀羅尼** `[B]`: 難を逃れる説話が多くあります。
  - 『今昔物語集』巻14第42：藤原常行が美福門のあたりで鬼の群れに遭い、衣に縫い込まれた尊勝陀羅尼で助かります。
  - 『大鏡』：藤原師輔が尊勝陀羅尼を誦して難を逃れます。
  - 『江談抄』：小野篁と藤原高藤の話があります。
- **朝日** `[B]`: 経を読むうちに朝日が昇り、鬼が消える話が一般的だとされます。
- **歌** `[B]`: 『口遊』『袋草紙』に、酔っているふりをする歌が伝わるとされます ※要原典照合。

### 1-4 別の伝え

- 節分を百鬼夜行日とする文献があります（『増補下学集』） `[B]` ※要原典照合。
- 徳島の「夜行さん」の伝承では、大晦日・節分・庚申の夜・夜行日に夜歩きを戒めます `[C]`【Web確認】。夜行日の日取りは、1-1 の表と同じです。

### 1-5 巡る頻度（計算）

史料の記載ではなく、日取りから計算した値です。

- 十二支は12日で一巡するので、百鬼夜行日は12日ごと、月に2〜3回来ます。
- 朔（新月）の日が百鬼夜行日に当たる確率は、月あたり12分の1です。年に1回ほど重なります。
- 日食は朔の日にしか起きません。

## §2 出雲の神在月（旧暦10月）

### 2-1 伝えの広まり 【Web確認】

- 神々が出雲に集まるという説は、『奥義抄』などに見えるとされます `[A]` ※要原典照合。
- この説は、出雲大社の御師が広めた語源の俗解とされます。「神無月」の語源そのものは不詳です。
- 出雲で10月を「神在月」と呼ぶことは、中世には唱えられていました `[A]`。由阿『詞林采葉抄』（1366年成立）に用例があるとされます ※要原典照合。

### 2-2 佐太神社の神在祭 【Web確認】

佐太神社の公式説明によります `[B]`。

- 神在祭は、文献上もっとも古くから行われているとされます。祭の次第は、約500年前の記録とほぼ同じ内容だといいます。戦国期に行われていたことになります。その記録の史料名は確かめていません ※要原典照合。
- 日取りは、陰暦10月11日から25日までの15日間でした。
  - 11〜17日が上忌、18〜25日が下忌です。
  - 18日に神迎えをして境内に注連縄を引き渡し、25日の神等去出が終わるまで謹慎斎戒に服しました。
  - のちに、間に「中根」という3日間の緩和日が設けられました。
- 明治30年ごろから陽暦11月に改め、下忌だけを行うようになりました。現在は11月20〜25日です。

### 2-3 出雲大社と万九千神社 【Web確認】

- **出雲大社** `[B]`: 旧暦10月10日の夜に稲佐の浜で神迎え、11〜17日に神在祭、17日と26日に神等去出祭を行います。
- **万九千神社** `[B]`: 神々が出雲で最後に立ち寄る所とされます。神々はここで直会をしてから帰る、と伝わります。
  - もとは斐伊川の中洲にあり、**寛文10年（1670年）に洪水のため遷されました**。
- 神々が発つ日を17日とする資料と26日とする資料があります ※要原典照合。

### 2-4 期間中の慎み（お忌み） 【Web確認】

- 佐太神社は、神在祭を「歌舞音曲、喧騒、造作等も慎む禁忌の祭」と説明しています `[B]`。
- 出雲大社の神在祭についても、祭りの踊りや音楽を控えめにし、かつては大工仕事や建設工事を休んだ、とする解説があります `[B]`。
- 土地では、この時期を「お忌みさん」と呼びます `[C]`。

### 2-5 龍蛇 【Web確認】

- 「お忌み荒れ」のころ浜に上がる龍蛇（セグロウミヘビ）は、竜宮の使い、神々の先導役とされます `[C]`。
- 佐太神社では、浜に上がったセグロウミヘビを神の使いとして奉納します `[B]`。
- 「お忌み荒れ」の天気や風向きの中身は、確かめられていません ※要原典照合。

### 2-6 神々が集う理由 【Web確認】

佐太神社の公式説明によります `[B]`。神社ごと、時代ごとに説明が異なるとされます。

- 佐太神社は、伊弉冉尊の神陵（比婆山）を遷し祀った社と伝えます。
- 旧暦10月は伊弉冉尊が神去った月で、八百万の神は母神を偲んで集まる、と説明しています。卜部家または陰陽道の説による、とあります。
- 「神々はまず出雲大社に立ち寄る」という伝えは誤伝だ、と佐太神社は述べています。

### 2-7 留守神と、出雲に行かない神 【Web確認】

各地の民俗伝承で、いつからの伝えかは確かめられていません `[C]`。

- 留守神は、荒神（竈の神）と恵比須が多いとされます。10月に恵比須講を行う地方があります。
- 諏訪明神は、龍の姿があまりに大きいため「出向かなくてよい」とされた、という伝えがあります。
- 能登には、神々が出雲に集う間も建御名方神だけは留まって守る、という伝えがあります。

## §3 出雲編の年表・地理との照合

設定を足したのではなく、すでにある年表と突き合わせた結果です。意図して合わせたものかは分かりません。

- **稲佐の浜**: 主人公が流れ着く浜は、神迎えの浜です。
- **万九千社**: 第三幕（永禄5年の初冬）の舞台です。永禄年間にはまだ斐伊川の中洲にあったことになり、舟橋普請の描写と合います。
- **霜月**: 第五幕の決戦は永禄9年の霜月（11月）です。神々が発った直後の月にあたります。

## §4 ゲーム設計への提案 `[D]`

決定と案の中身は、`data/combat_5_attributes.json` の `impurity_curse_and_hyakki_yagyo_2026_11_14` にあります。ここでは、考証との対応だけを示します。

| 設計 | 考証との対応 |
| :--- | :--- |
| 百鬼夜行が起きうる夜を、百鬼夜行日に限る | §1-1 の日取りをそのまま使えます |
| 百鬼夜行日と新月が重なる夜を、最大規模にする | 組み合わせは創作です。頻度は §1-5 の計算によります |
| 日蝕は昼に来て、特殊な荒魂が出る | 百鬼夜行日とは別の出来事です。企画書 10-4 と 06 §4 によります |
| 里の人は忘れ、陰陽師と古い暦だけが覚えている | §1-2 の「重んじられなくなった」という推測に基づく見せ方です |
| 陰陽道の「暦読み」で前もって読める | 暦注なので、暦を読める者には分かります（09 §5-1） |
| 出雲では、神在祭の間は百鬼夜行が来ない | 創作です。期間は §2-2・§2-3 の日取りを使えます |
| 期間中の慎みを、御神徳の加点にする | §2-4 の慎みに基づきます。罰にしない点は翻案です |
| 龍蛇を、神々が来る吉い前触れにする | §2-5 によります |
| 出雲以外の国は、10月に守りが弱まる | 神無月の俗解（§2-1）に基づく翻案です |
| 留守神を祀る所と、信濃は弱まらない | §2-7 の伝承に基づく翻案です |

**月の数え方について**: 百鬼夜行日を節月で数えるか、暦の月で数えるかは未定です。節月のほうが史料に近いという指摘があります（§1-2）。

# 『荒魂の國』補遺3 全国一宮の霊山・街道・結界配置（改訂版2）

- **対象**: 1540～1580年を中心に／2026年10月25日
- **Google Docs 原典（非公開）**: 『荒魂の國』補遺3 全国一宮の霊山・街道・結界配置

## 1. 位置づけと証拠区分
「全国一宮を直線で結ぶと列島結界が完成する」という構図はゲーム用創作`[D]`であり、史実で確認できる①方位による守護（鬼門・王城鎮護）、②寺社領・境内の境界（四至・牓示）、③入山・入域の制限（女人禁制・女人結界門）、④参詣道・御師ネットワークを部品として組み合わせて構築する。

## 2. 根拠のある主要接続例
- **(1) 駿河・富士山の道者経済**: 大宮・村山口、須山口、須走口と山役銭。『公文富士氏文書』（永禄6年＝1563年道者帳）。富士山頂の「内院散銭」取得権をめぐる今川氏（1533年辻之坊宛）・武田氏（1577年須走宛）の判物（[富士山 - Wikipedia](https://ja.wikipedia.org/wiki/%E5%AF%8C%E5%A3%AB%E5%B1%B1)）。
- **(2) 参詣網**: 熊野古道（九十九王子）、高野山町石道（慈尊院から壇上伽藍180基＋奥之院36基＝計216基の町石と女人道：[高野山町石道 - Wikipedia](https://ja.wikipedia.org/wiki/%E9%AB%98%E9%87%8E%E5%B1%B1%E7%94%BA%E7%9F%B3%E9%81%93)）、西国三十三所（15世紀中頃に番付固定）、伊勢御師（戦国大名との師檀契約・伊勢暦配布）、信濃善光寺聖。
- **(3) 白山三馬場と四至・牓示**: 越前馬場（平泉寺）・加賀馬場（白山比咩神社）・美濃馬場（長滝神社）の三禅定道。荘園・寺社領の四隅（艮・巽・坤・乾）に本牓示を打つ中世境界慣行（吉田敏弘『四至牓示から境界線へ』：[國學院雜誌論文PDF](https://k-rain.repo.nii.ac.jp/record/278/files/kokugakuinzasshi_118_05_001.pdf)）。
- **(4) 鬼門鎮護と女人結界**: 比叡山延暦寺と赤山禅院（皇城表鬼門・金網の猿）、大峰山上ヶ岳の女人結界門、立山芦峅寺の姥堂、出羽三山の七方八口。

## 各項目の詳細調査解説

### 4-1. 1563年（永禄6年）の日蝕検証
- **典拠**: NASA Eclipse Web Site / 国立天文台暦計算室「日月食等データベース」
- **事実**: 1563年（ユリウス暦）において日本本土で観測された皆既日食は存在しない。同年の中心食は6月20日の高緯度金環日食、および12月15日の南半球金環皆既日食である。
- **裁定**: 小説第四幕の「黒き日輪」は、常世の地脈決壊に伴う天変異変、またはゲーム演出としての創作 `[D]` である旨を考証資料第1版・第5章に明記する。

### 4-2 & 4-3. 毛利隆元の急死と白鹿城の吉川元春
- **典拠**: 『松江市史』通史編2（中世）、『毛利元就卿伝』、『陰徳太平記』
- **事実**: 
  - 白鹿城攻め全体の総大将は毛利元就であり、後方の宍道湖北岸「洗合（荒隈城）」に本陣を置いていた。
  - 嫡男・毛利隆元は永禄6年8月4日、出雲出陣の直前に安芸佐々部で数え41歳で急死。元就は悲嘆に暮れつつも、白鹿城攻めを断行した。
  - 元春は先鋒の大将として白鹿山の山麓に布陣し、坑道戦や力攻めを直接前線で指揮した。
- **小説への反映**: 第四幕冒頭の元春の台詞に「父上（元就）は洗合の本陣より動かれぬが、急死した兄・隆元の無念を晴らすためにも、この白鹿はわしが落とす」という一文を入れることで、歴史の深みと元春の悲壮な覚悟が劇的に際立つ。

### 4-4 & 4-5. 永禄5年冬の高瀬城（米原綱寛）と毛利本陣（洗合）
- **典拠**: 『出雲市史』、松安六治郎「尼子十旗探訪 高瀬城編」、『斐川町史』
- **事実**:
  - 永禄5年（1562年）夏から秋にかけて毛利軍が出雲へ侵入した際、尼子十旗の第6・高瀬城主の米原綱寛は戦わずに毛利軍に降伏した。
  - 毛利元就はそのまま宍道湖北岸を進み、年末から翌年にかけて荒隈城（洗合城）に本陣を構えた。
- **小説への反映**: 第三幕の城代・目付が若者たちを厳しく尋問した理由は、「毛利に降ったばかりの城であり、尼子残党の奪還や間者を極度に恐れていた」という史実の政治状況と完璧に合致します。小説の心理描写として補強可能。

### 4-6. 「玉鋼」の呼称成立
- **典拠**: 和鋼博物館「たたらの話し」、日本美術刀剣保存協会
- **事実**: たたら製鉄で生み出される最上級の鋼を「玉鋼」と呼ぶようになったのは、近世末期（幕末）〜明治以降の日本刀保存運動・近代製鉄の分類以降である。中世当時は「鉧（けら）」「真金（まがね）」「上鋼」「卸鉄」などの呼称が使われた。
- **裁定**: 企画書・ゲームUIではユーザーへの分かりやすさから「玉鋼」をマスター用語として使用し、作中台詞や考証資料では「真金（まがね）」と並記して `[D]` 注記を付す。

### 4-7. 天秤鞴・高殿の成立
- **典拠**: 和鋼博物館第1展示室解説、森俊勇論文
- **事実**: 二人踏みの天秤鞴は元禄年間（1690年代）以降の考案、巨大な高殿建築による永代たたらは18世紀の確立。
- **裁定**: すでにオーナー確認済み通り、**「職人技術のロマンを体感するための意図的な先取り `[D]`」** として考証資料に記録。

### 4-8. 戦国期の鉄穴流しの環境影響
- **典拠**: 森俊勇『「たたら製鉄」と「鉄穴流し」による山地の荒廃と土砂災害』（2017）
- **事実**: 山の斜面を崩して比重選鉱を行う鉄穴流しは、下流の河床上昇（斐伊川の天井川化）や農業用水の汚染をもたらし、農民との間に激しい「水論・砂鉄流し訴訟」を頻発させた。
- **小説への反映**: 序幕・第三幕で語られる「山穿ちと川の濁り、それに怒った泥の猪神」の民俗的背景として学術的に完全に裏付けられた。

### 4-9. 国引き神話の「二本の杭」と「二本の綱」
- **典拠**: 『出雲国風土記』意宇郡条
- **事実**:
  - **西の杭**: 佐比売山（さひめやま / 三瓶山） ➔ **西の綱**: 薗の長浜（出雲市海岸線）
  - **東の杭**: 火神岳（ひのかみのたけ / 伯耆大山） ➔ **東の綱**: 夜見の島（弓ヶ浜半島）
- **小説への反映**: 第五幕の祝詞において、出雲国内の四社に加え「西の佐比売山、東の火神岳の二大神杭」を言及することで、出雲平定編から次回作（西の石見銀山・佐比売山編／東の伯耆・火神岳編）への雄大な世界観の広がりが完成する。

### 4-10. 石見銀山掘子による白鹿城水の手断ち
- **典拠**: 『陰徳太平記』巻三十八「白鹿城水の手破られ落城の事」
- **事実**: 「毛利元就、石見国大森銀山の金掘りども数百人を召し寄せ、昼夜を分たず地下を掘らしめ、白鹿城の本丸水の手（大井戸）を穿ち切りて落城せしむ」と明記されている。
- **裁定**: 小説第四幕の間歩（坑道）戦の着想元として完全な軍記史料 `[B]` の典拠を確認。考証資料第1版に巻号を正式追記する。

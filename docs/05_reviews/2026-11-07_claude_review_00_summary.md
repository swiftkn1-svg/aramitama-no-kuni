## 1. 最優先：作品全体のテーマ・構成に関わるもの【高】

### 1-1. 荒魂が「和魂へ還る」場面の演出が未実装（五幕1-1）
- **設定は定義済み**: 企画書 10-2（L543）に、荒魂4体の正体・荒ぶった理由・鎮魂後の姿が書かれている（例：水大蜘蛛＝綱の神力が穢れで反転したもの、黒蛇＝鎮魂で大水脈の守り神へ昇華）。裁定③と JSON も同じ内容で、考証資料も「荒魂＝悪霊とはしない」と明記している。
- **未実装なのは演出**: 小説ではどの幕も「霧散」「崩れ落ちる」「断末魔」で終わり、還る場面がない。オーナーも、表現方法を課題として認識している。
- **対応**: 企画書 10-8 ②の「白い光となって山へ還る」という既存の表現を使い、各幕の決着に**「還る先（方角・場所）」と「正体の名指し」**の数行を足す。
  - 第二幕：白い糸となって薗の長浜へ流れ、国引きの大綱への伏線にする。
  - 第五幕：白銀の龍神が斐伊川の源（奥出雲）へ昇る。

### 1-2. 第三幕に「泥の猪神」戦が存在しない（五幕1-2）
- 索引・CSV（No.7）・JSON・裁定③には記載があるのに、第三幕の本文にはない。企画書 10-2 にも正体の定義しかなく、場面の段取りはない。
- **対応**: 場面案はアルテの作業セッション内にある可能性が高いので、まずアルテに確認する。そのうえで、場面を復元するか、資料側を削除するかを決める。復元の参考案：舟橋普請の終盤に、仮注連縄の「潮止め」（企画書10-4④）で谷口に閉じ込める。

### 1-3. 看板システム「影の潮汐」と描写の物理的な矛盾（二幕1-1／四幕1-1）
- **第二幕**: 北山の影が、南の湿地・古祠に落ちている。太陽は南を通るので、北の山の影は北へ落ち、南側には落ちない。
- **第四幕**: 日蝕で影が「幾丈にも伸びる」。日蝕では太陽の位置は変わらず暗くなるだけなので、影は消え、一面が陰に沈む。
- **対応**: 第二幕は、影を落とす地形を祠の西〜南西へ移す（古祠の比定地＝二幕1-2と同時に解決）。第四幕は「影が消える」描写に変える。

### 1-4. 製鉄工程の矛盾（二幕2-1）
- 第二幕で、火床に入れた砂鉄から直接要釘ができている。たたら（製錬）を経ないと鉄にならない。
- **対応**: 第二幕に小さな野だたらの工程を一段落入れる。第三幕の本格たたらとの格の差もはっきりする。

## 6. 全幕を通して特に良かった点（改稿でも残してほしいもの）

- **食と時間のテーマ**：序幕の山鳥汁 → 稲佐の浜の猪汁 → 野営の生姜汁 → 夜祭りの屋台。「腹いっぱい美味い飯を食うて、お前の時間を生き抜く」が、作品の芯として全幕を貫いている。
- **数値ゲージを使わない限界表現**：道祖神の濡れ具合、松明の縮み（一尺 → 五寸 → 親指の先）、一炷の香が切れる瞬間、石仏の汚れ方。企画書10-4の仕様が、そのまま物語の手触りになっている。
- **音で腕を測る職人の世界観**：序幕「今の音は悪くない」→ 第三幕 村下「音で分かるわい」→ 第五幕 山立「いい音が鳴るようになった」。成長が音で一貫して語られている。
- **仕様と物語の高い連携**：第四幕のパターンC（龍穴の直打ち → 頭三寸 → 井桁座 → 祝詞）は、仕様書と細部まで一致している。
- **史実の拾い方**：石見の金掘りと地下での鉢合わせ、月山富田の開城時期、京羅木山の本陣、七曲、勝日高守神社。
- **民俗の昇華**：金屋子神が死穢を忌まない伝承 `[C]` を、「先代村下の焼骨で死穢を神火に反転させる」見せ場 `[D]` へ。
- **枠構造の円環**：序幕の琵琶法師の語りが、第五幕の太平の夜祭りで回収される。
- **「大軍の戦争は起きない」原則の物語化**：観察と職能による城代の説得、敵味方なき共闘、元春の約束の履行。

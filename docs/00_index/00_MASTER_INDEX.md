  - **用途**: 戦国時代（寛永年間以前）の斐伊川が出雲平野を西へ流れて「神門水海（入海）」に注いでいた史実、および天井川・川違えの考証根拠。
- [**松江市史研究12号（島根大学リポジトリ）：中世斐伊川の東西分流**](https://coc.lib.shimane-u.ac.jp/files/attach/3/3180/%E6%9D%BE%E6%B1%9F%E5%B8%82%E6%AD%B4%E5%8F%B2%E5%8F%A2%E6%9B%B814.pdf)
  - **用途**: 古代〜中世の斐伊川が「本流は西流して神門水海に注ぎつつ、一部は東流（分流）して宍道湖に注ぐ二股構造」であったことの学術根拠。
- [**産業技術総合研究所 地質調査総合センター：『出雲平野と宍道湖・斐伊川の砂』（地質ニュース671号）**](https://www.gsj.jp/data/chishitsunews/2010_07_10.pdf)
  - **用途**: 風土記〜中世の古地理（西の神門水海・東の宍道湖）と、上流の花崗岩地帯から流下する真砂砂鉄の堆積プロセスの根拠。
- [**いずもる（出雲地区地域振興）：『神門水海は湿地から新田へ（菱根池と堀貫川）』**](https://www.izm.gr.jp/izumoru/readmore.php?gid=236&tno=-1)
  - **用途**: 出雲大社（杵築大社）東方の弥山南麓に広がっていた大湿地「菱根池」と「神門水海」の位置関係。
- [**土木学会論文集：『大正・昭和初期の大橋川改修による宍道湖の環境変化と住民の共生』**](http://library.jsce.or.jp/jsce/open/00013/1999/27-0063.pdf)
  - **用途**: 佐陀川開削（江戸中期）や大橋川改修以前の宍道湖・中海の塩分環境変遷（東の中海から大橋川を経て西の宍道湖へ薄まる塩分グラデーション）の根拠。
- [**島根県公式：『宍道湖・中海の概要（塩分濃度差）』**](https://www.pref.shimane.lg.jp/industry/suisan/shinkou/kawa_mizuumi/yutakana/shinjikonakaumi.html) ＆ [**『汽水域の豊かな恵み』**](https://www.pref.shimane.lg.jp/industry/suisan/shinkou/kawa_mizuumi/yutakana/kisuiiki.html)
